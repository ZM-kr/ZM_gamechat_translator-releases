# 사용 안내 · 1.0.4

처음에는 ZIP 안의 **START-HERE.txt** 순서대로 진행하세요. 처음 실행하면 **설정 마법사**가 열리고, 제어판 위쪽 **설정 마법사** 버튼으로 언제든 다시 열 수 있습니다. 처음 사용할 때는 인식 결과와 번역 표시가 정상인지 확인하세요. 설정 중 문제가 생기면 오류 문구와 함께 제보해 주세요.

Windows x64용이며 .NET 런타임과 글자 인식(OCR) 모델이 포함되어 있습니다. **내장 OCR은 언어팩 없이 영어·중국어를 인식하며 한국어를 보완합니다. 다른 언어는 Windows OCR에서 해당 지원 언어팩을 설치해 인식할 수 있습니다.** 최소 대상은 Windows 10 2004 이상입니다. macOS/Linux/ARM64용 배포본은 없습니다.

## 안티치트 및 사용 책임 안내

이 앱은 게임 프로세스에 연결하거나 게임의 메모리를 읽고 쓰지 않습니다. 게임 DLL을 주입하거나 게임의 네트워크 통신을 가로채지 않으며, 게임 내부에 후킹하지 않습니다. 화면 캡처에는 데스크톱 픽셀을 읽는 GDI BitBlt를 사용하고, 단축키는 Windows의 RegisterHotKey로 등록합니다. 현재 앱 소스에는 OpenProcess, ReadProcessMemory, WriteProcessMemory, SetWindowsHookEx 호출이 없습니다.

지정한 데스크톱 영역을 캡처한 뒤 내장 OCR 또는 Windows OCR로 글자를 인식하고, 번역에 필요한 텍스트를 선택한 번역 API 또는 로컬 서버로 보냅니다. 화면 캡처를 이용한다는 점에서는 스크린샷·화면 녹화 도구와 비슷하지만, **게임이나 안티치트가 이 앱을 동일하게 취급하거나 허용한다는 뜻은 아닙니다.**

**어떤 게임에서도 제재 없이 사용할 수 있다고 보장하지 않습니다.** 안티치트의 탐지 기준은 공개되지 않을 수 있고 수시로 변경됩니다. 게임과 함께 실행되는 외부 프로그램이라는 이유로 탐지되거나 제한될 가능성을 배제할 수 없습니다. 사용 전 해당 게임의 외부 도구 사용 정책을 확인하세요.

**사용 여부와 그에 따른 위험은 사용자 본인이 판단하고 부담합니다.** 관련 법령이 허용하는 범위에서 개발자와 기여자는 이 앱 사용으로 인한 계정 정지·경고·기타 계정 제재, 성능 저하, 데이터 손실 또는 그 밖의 결과에 대해 책임을 지지 않습니다. 이러한 위험에 동의하지 않는다면 사용하지 마세요.

## 번역 엔진 고르기

**번역 설정**(또는 마법사 1단계)에서 먼저 **일반 번역**과 **AI 번역** 중 하나를 고르고, 그 안에서 엔진을 고릅니다. 선택한 엔진에 필요한 항목만 표시됩니다.

### 일반 번역

이 안내는 구글 클라우드 API를 권장합니다. 번역 설정에서 구글 클라우드 번역을 선택하고 API 키를 입력하세요.
- **구글 클라우드 번역 (권장):** 본인 Google Cloud API 키로 번역합니다. **매달 50만 자까지 무료**이고, 넘으면 100만 자당 약 $20입니다(원문 글자만 계산). 무료 한도만 쓰더라도 결제 계정(카드) 등록이 필요합니다.
  - 마법사가 발급 단계를 차례로 안내합니다: 프로젝트 → 결제 연결 → API 사용 → API 키 → 붙여넣기 → 연결 확인. 실패하면 어느 단계를 고칠지 알려 줍니다.
  - **월 상한:** 기본 450,000자입니다. 상한에 닿으면 Google로 보내지 않고 번역 실패로 표시합니다. 이 PC에서 보낸 글자만 세므로, 같은 키를 다른 곳에서도 쓰면 여유를 두세요. 월은 미국 태평양 시간 기준이라 한국 시간 매월 1일 오후에 초기화됩니다.
- **구글 무료 번역 (대안):** 계정·API 키 없이 인터넷 연결만으로 사용합니다. 비공식 무료 연결이라 요청 제한·실패가 생길 수 있습니다.
- **Bing 무료 번역 (비공식):** 계정·키 없이 사용하며, 게임 말투와 중국어가 구글 무료보다 자연스러운 편입니다. 비공식 방식이라 언제든 막힐 수 있고, 실패한 채팅은 구글 무료 번역으로 대신 번역합니다.
- **Microsoft 번역 (Azure):** Bing과 같은 엔진의 공식 API입니다. 다른 엔진보다 설정이 복잡합니다. Azure 가입(카드 본인 확인), Translator 리소스 만들기, 키·지역 복사까지 여러 단계가 필요합니다. 처음이라면 Bing 무료 번역이나 구글 클라우드 번역이 더 간단합니다. 마법사 안내대로 Azure에서 Translator 리소스를 **Free F0** 계층으로 만들고 키와 지역을 입력하세요. 매달 200만 자까지 무료이고, 다 쓰면 요금 없이 그달 번역이 멈춥니다. Azure 가입에는 본인 확인용 카드 등록이 필요합니다.
- 일반 번역은 문장 단위로 번역하며 이전 대화·추가 번역 지침·문맥 조건 용어를 적용하지 않습니다.

### AI 번역
앞뒤 대화와 게임 설명·용어를 이해해 은어와 말투를 살리지만, 일반 번역보다 느리고 계정·키·서버가 필요합니다.
- **체험하기:** AI 번역을 고르면 나오는 **체험하기** 버튼을 누르세요(마법사와 번역 설정 모두에 있습니다). 별도 창에서 **Google Gemini 3.8 Flash(추천)** 또는 **Groq**를 고르고 ① 키 발급 페이지 열기 → ② 키 붙여넣기 → ③ **연결 확인**을 누릅니다. 모델 선택과 예문 번역까지 자동으로 확인합니다.
  - 무료 사용량이 적어 **채팅이 많은 게임에서는 도중에 한도에 걸려** 번역이 실패할 수 있습니다. 한도 초과면 오류 문구로 알려 줍니다.
  - Gemini 무료 등급에서는 보낸 채팅과 번역 결과가 Google 서비스 개선에 쓰이고 사람이 검토할 수 있습니다.
- **클라우드 API:** OpenAI·Gemini·DeepSeek·OpenRouter·Groq·Azure 프리셋을 누르고 모델 ID와 본인 API 키를 입력합니다. 요금은 각 서비스 기준입니다.
- **Codex:** [공식 CLI 설치 안내](https://learn.chatgpt.com/docs/codex/cli)에서 **Windows**를 골라 설치하고, Windows PowerShell에서 `codex login`으로 로그인합니다. `codex login status`로 확인할 수 있습니다. 앱에서 **Codex 자동 찾기**를 누르세요. ChatGPT 앱·Codex 설치판·npm·VS Code 확장 등에 들어 있는 Codex를 모두 찾아 **가장 최신 버전**을 사용하며, 사용 중인 버전과 설치 위치가 표시됩니다. 자동 찾기에 실패하면 **찾아보기**에서 Windows용 `codex.exe`를 지정합니다(`codex.cmd`나 WSL 내부 파일은 제외). ChatGPT 계정 한도가 적용되고, 응답이 API보다 느립니다. 사용한 모델을 제보에 적어 주세요.
- **Claude (계정 로그인):** Anthropic 안내에 따라 Claude Code를 설치하고, Windows PowerShell에서 `claude`를 실행해 로그인합니다. 앱에서 **Claude Code 자동 찾기**를 누르면 설치된 Claude Code를 모두 찾아 **가장 최신 버전**을 사용하고, 로그인 상태와 요금제 종류, 고를 수 있는 모델 목록을 보여 줍니다. 번역 모델은 **Sonnet(번역 추천)**을 권장하며, Haiku는 요금제 한도를 적게 씁니다. 자동 찾기에 실패하면 **찾아보기**에서 `claude.exe`를 지정합니다. 사용량은 본인 Claude 요금제(Pro·Max) 한도에서 차감되며, 게임 채팅을 오래 번역하면 한도가 빨리 줄 수 있습니다. 앱은 Claude 계정 정보를 읽거나 저장하지 않습니다. Anthropic 약관과 정책에 따라 이 방식이 제한되거나 바뀔 수 있습니다.
- **로컬 모델:** 실행 중인 OpenAI 호환 서버(Ollama, LM Studio)의 주소와 로드된 모델이 필요합니다. 서버는 ZIP에 포함되지 않습니다.

연결은 **진단 · 테스트 → 선택한 엔진으로 번역** 또는 마법사의 **연결 테스트**로 확인합니다. 프로그램에 번역 계정이나 사용료가 포함되지는 않습니다.

## 게임 설정

- **게임 프로필:** WarDogs라면 **WarDogs 프리셋 적용**을 누르면 채널 인식과 팀 색상이 한 번에 설정됩니다.
- **번역 중에는 다른 창으로 전환해도 지정한 화면 영역을 계속 읽습니다.** 그 자리에 다른 앱이 보이면 그 글자도 번역 서비스로 전송됩니다. 게임을 하지 않을 때는 번역을 중지하세요.
- **채팅 영역 설정:** 채널·닉네임·본문 전체와 위아래 여백을 포함하세요. 해상도·화면 배율·게임 창 위치를 바꾸면 영역을 다시 확인합니다.
- **팀 색상 (WarDogs):** 채팅 줄 왼쪽의 진영 표지(그린 ●, 레드 ▼, 블루 ■) 색을 읽어 번역창의 닉네임을 같은 색으로 표시합니다. **채팅 영역에 표지까지 포함**해야 하며, 표지를 찾지 못한 줄은 흰색입니다.
- **OCR 설정 탭:** 기본은 내장 OCR입니다. 다른 언어를 인식하려면 **고급 · Windows OCR 호환 모드**를 선택하고 해당 언어팩을 설치한 뒤 사용할 언어를 선택하고 **저장·적용**하세요. 지원 범위는 Windows OCR에서 제공하는 언어에 따릅니다.
- **번역창:** 위치와 크기는 **번역 중지 → 번역창 잠금 해제** 후 조절합니다. 번역 중에는 클릭이 게임으로 통과합니다. 채팅이 없을 때 빈 번역창이 보이지 않는 것은 정상입니다.
- 처음에는 창 모드 또는 테두리 없는 창 모드로 시험해 주세요. 게임마다 캡처·오버레이 동작과 외부 프로그램 관련 정책이 다를 수 있으며 모든 게임에서 검증된 것은 아닙니다.

## 내 채팅 번역

번역 중 게임에서 **Shift+Enter**를 누르면 입력 창이 뜹니다. 한국어로 입력하고 **Enter**를 누르면 선택한 언어로 번역해 클립보드에 넣으니, 게임 채팅에서 **Ctrl+V**로 붙여 넣으세요. **↑/↓**로 언어를 바꾸고 **Esc**로 닫습니다. 언어·기본 언어·단축키·확인 후 복사는 **내 채팅 번역** 탭에서 바꿉니다. 번역 중에는 다른 앱의 Shift+Enter도 이 창을 엽니다.

## 로그와 제보

예기치 않은 종료 시에는 채팅·닉네임·API 키·오류 메시지 원문을 제외한 오류 종류, 발생 위치, 시각, 앱 버전만 `%APPDATA%\ZMGameChatTranslator\errors\last-error.json`에 최근 1건 보관합니다. 자동 전송하지 않습니다.

기본값은 **세션 로그 자동 기록 꺼짐 / 채팅 내용 포함 꺼짐**입니다. 기본 상태에서는 제보 양식으로 문제와 발생 시각을 알려 주세요. 파일 기록이 꺼진 세션은 문제 표시·분석·ZIP 내보내기용 파일을 만들지 않습니다.

조사에 로그가 필요하면 **실사용 로그 → 세션 로그 자동 기록**을 켜고 **저장·적용**한 다음 새 세션을 시작합니다. 원문·번역문·닉네임·OCR 원문·메모까지 필요할 때만 **내용 포함**도 켜세요.

로그를 켠 세션에서는 문제 행을 고르고 메모를 입력한 뒤 **OCR 오류 / 오역 / 중복**을 누릅니다. **채팅 누락**은 행을 선택하지 않고 표시합니다. 플레이 후 **번역 중지 → 목록 새로고침 → 세션 선택 → 로그 분석 → 선택 세션 ZIP 내보내기**로 해당 세션을 내보냅니다. ZIP은 자동 업로드되지 않습니다. 내용을 확인한 뒤 프로그램을 전달한 개발자에게 개인적으로 보내세요. 공개 게시판에 원본 로그를 올리지 마세요.

번역을 위해 채팅 텍스트(AI 번역은 화자·채널·주변 문맥·용어집 포함)를 선택한 서비스로 보냅니다. OCR은 이 PC에서 처리하고 화면 이미지는 보내지 않습니다. 내용 로그를 끄는 것과 번역 서비스로 보내는 것은 별개입니다.

문제 제보에는 [양식](BUG-REPORT.md)을 사용하세요. API 키, `settings.json`, Codex 인증 폴더는 필요하지 않습니다. 화면을 첨부한다면 다른 앱과 개인 정보를 가려 주세요.

## 업데이트·되돌리기·삭제

- **업데이트:** 새 버전이 공개되면 앱 위쪽에 안내가 나타납니다. **다운로드 페이지 열기**로 새 ZIP을 받으세요(자동 설치는 하지 않습니다). 앱을 종료하고 새 ZIP을 **새 폴더**에 풉니다. 이전 버전과 동시에 실행하지 마세요. 설정은 `%APPDATA%\ZMGameChatTranslator\settings.json`에 있어 이어서 사용됩니다. 기존 설정이 있으면 설정 마법사는 자동으로 열리지 않습니다.
- **되돌리기:** 앱을 종료하고 보관한 이전 버전 실행 파일을 실행합니다. 업데이트 전에 설정 파일을 개인 보관용으로 복사해 두면 복구에 도움이 됩니다. 설정 파일은 다른 사람에게 보내지 마세요.
- **앱 삭제:** 종료 후 압축을 풀었던 프로그램 폴더를 삭제합니다. 설정·로그·구글 클라우드 사용량 기록(`google-cloud-usage.json`)은 `%APPDATA%\ZMGameChatTranslator`에 남으니, 필요 없을 때 직접 삭제하세요. `%LOCALAPPDATA%\ZMGameChatTranslator`에는 Codex 조회·요청용 임시 자료가 남을 수 있습니다.
- **로그 보관:** 새 세션을 시작할 때 오래된 세션부터 자동으로 삭제해 보관 범위(기본 20개·256MB) 안으로 맞춥니다. 보관할 세션 수와 최대 용량은 **실사용 로그** 탭에서 바꿀 수 있습니다. 필요한 세션은 미리 ZIP으로 내보내세요. 한 세션의 기록이 32MB에 닿으면 그 세션의 파일 기록만 멈춥니다.
- **실행 차단:** 서명되지 않은 배포판입니다.
  - "Windows의 PC 보호" 경고는 `SHA256SUMS.txt`로 받은 ZIP이 맞는지 확인한 뒤 **추가 정보 → 실행**으로 열 수 있습니다.
  - **스마트 앱 컨트롤(SAC) 차단:** 받은 파일과 배포자를 신뢰하고 설정 변경에 동의한다면 **Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정 → 끄기**를 선택하고, 상태를 확인한 뒤 앱을 다시 실행할 수 있습니다. 이 앱만 허용하는 기능은 없으며 **PC 전체의 SAC 보호가 꺼집니다.** Defender 실시간 보호는 켜 두세요.
  - 변경 전 Windows 업데이트와 설정 화면의 재활성화 안내를 확인하세요. 최신 업데이트에서는 SAC를 다시 켤 수 있지만, 이전 버전에서는 Windows 초기화·재설치가 필요할 수 있습니다. 다시 켜면 앱이 재차 차단될 수 있습니다. 변경을 원하지 않거나 설정이 없거나 계속 차단되면 경고 문구와 Windows 버전을 제보해 주세요. 단계별 안내는 ZIP 루트의 **START-HERE.txt**에 있습니다.
