# 사용 안내 · 1.1.2

ZM GameChat Translator는 게임 채팅을 화면에서 읽어 한국어로 번역하는 범용 게임 채팅 번역기입니다. 게임마다 설정을 **프리셋**으로 나누어 저장하며, WarDogs용 프리셋이 기본으로 포함되어 있습니다.

처음에는 ZIP 안의 **START-HERE.txt** 순서대로 진행하세요. 처음 실행하면 **설정 마법사**가 열리며, 제어판 오른쪽 아래 **설정 마법사** 버튼으로 언제든 다시 열 수 있습니다. 처음 사용할 때는 인식 결과와 번역 표시가 정상인지 확인하세요. 설정 중 문제가 발생하면 오류 문구와 함께 제보해 주세요.

Windows x64용이며 .NET 런타임과 글자 인식(OCR) 모델이 포함되어 있습니다. **내장 OCR은 언어팩 없이 영어·중국어를 인식하며 한국어를 보완합니다. 다른 언어는 Windows OCR에서 해당 언어팩을 설치해 인식할 수 있습니다.** 최소 지원 환경은 Windows 10 2004 이상입니다. macOS/Linux/ARM64용 배포본은 없습니다.

## 제어판 구성

| 탭 | 내용 |
|---|---|
| 실시간 번역 | 번역 기록, 다시 번역, 화면 글자 한 번 번역, 로그에 문제 표시 |
| 게임 | 프리셋 관리·내보내기·가져오기, 게임 정보, 채팅 영역, 게임 프로그램, 채팅 인식 규칙, 인식 보정 |
| 번역 | 번역 엔진 선택과 연결, API 키 발급 안내, 번역 동작 |
| 번역창 | 번역창 표시·위치·크기·글자·배경 |
| 내 채팅 번역 | 번역할 언어, 번역 확인, 게임 채팅 글자 수 제한, 입력 창 모양과 위치 |
| 음성 번역 | 보이스챗 번역 사용, 듣는 언어 (Windows 11 라이브 캡션) |
| 용어집·상용구 | 게임 용어와 자주 쓰는 문구 |
| 앱 설정 | 단축키, 알림 영역, 화면 캡처 숨기기, 글자 인식, 새 버전 확인 (모든 프리셋 공통) |
| 로그·진단 | 세션 로그, 로그 분석·내보내기, 번역 연결 테스트, OCR 원문 |

제목 옆에 **프리셋별** 표시가 있는 설정은 프리셋마다 따로 저장됩니다. API 키·단축키·로그·구글 클라우드 월 상한은 모든 프리셋에 공통으로 적용됩니다.

## 안티치트 및 사용 책임 안내

이 앱은 게임 프로세스에 연결하거나 게임의 메모리를 읽고 쓰지 않습니다. 게임 DLL을 주입하거나 게임의 네트워크 통신을 가로채지 않으며, 게임 내부에 후킹하지 않습니다. 화면 캡처에는 데스크톱 픽셀을 읽는 GDI BitBlt를 사용하고, 단축키는 Windows의 RegisterHotKey로 등록합니다. 채팅 영역에 게임이 표시되는지 확인할 때는 화면에 보이는 창과 그 프로세스 번호(GetForegroundWindow, WindowFromPoint, GetWindowThreadProcessId), 작업 관리자와 같은 프로세스 목록만 확인합니다. 보이스챗 번역을 켜면 Windows 라이브 캡션을 실행하고, 그 창의 글자를 화면 읽기 프로그램과 같은 UI 자동화로 읽습니다. 게임 창은 읽지 않습니다. 현재 앱 소스에는 OpenProcess, ReadProcessMemory, WriteProcessMemory, SetWindowsHookEx 호출이 없습니다.

지정한 데스크톱 영역을 캡처한 뒤 내장 OCR 또는 Windows OCR로 글자를 인식하고, 번역에 필요한 텍스트를 선택한 번역 API 또는 로컬 서버로 전송합니다. 화면 캡처를 이용한다는 점에서는 스크린샷·화면 녹화 도구와 비슷하지만, **게임이나 안티치트가 이 앱을 동일하게 취급하거나 허용한다는 뜻은 아닙니다.**

**어떤 게임에서도 제재 없이 사용할 수 있다고 보장하지 않습니다.** 안티치트의 탐지 기준은 공개되지 않을 수 있고 수시로 변경됩니다. 게임과 함께 실행되는 외부 프로그램이라는 이유로 탐지되거나 제한될 가능성을 배제할 수 없습니다. 사용 전 해당 게임의 외부 도구 사용 정책을 확인하세요.

**사용 여부와 그에 따른 위험은 사용자 본인이 판단하고 부담합니다.** 관련 법령이 허용하는 범위에서 개발자와 기여자는 이 앱 사용으로 인한 계정 정지·경고·기타 계정 제재, 성능 저하, 데이터 손실 또는 그 밖의 결과에 대해 책임을 지지 않습니다. 이러한 위험에 동의하지 않는다면 사용하지 마세요.

## 번역 엔진 선택

**번역** 탭(또는 마법사 1단계)에서 먼저 **일반 번역**과 **AI 번역** 중 하나를 선택한 뒤 엔진을 선택합니다. 선택한 엔진에 필요한 항목만 표시됩니다.

### 일반 번역

구글 클라우드 번역을 권장합니다. **번역** 탭에서 구글 클라우드 번역을 선택하고 API 키를 입력하세요.
- **구글 클라우드 번역 (추천):** 본인의 Google Cloud API 키로 번역합니다. **매달 50만 자까지 무료**이며, 초과 시 100만 자당 약 $20입니다(원문 글자 수 기준). 무료 한도만 사용하더라도 결제 계정(카드) 등록이 필요합니다.
  - 키 입력칸 옆 **API 키 발급하기**(또는 설정 마법사)에서 프로젝트 만들기 → 결제 계정 연결 → API 사용 → API 키 만들기 → 붙여넣기 → 연결 확인 순서로 안내합니다. 실패하면 어느 단계를 확인해야 하는지 알려 드립니다.
  - **월 상한:** 기본 450,000자입니다. 상한에 도달하면 Google로 전송하지 않고 번역 실패로 표시합니다. 이 PC에서 전송한 글자만 집계하므로, 같은 키를 다른 곳에서도 사용한다면 여유를 두고 설정하세요. 월 기준은 미국 태평양 시간이며 한국 시간 매월 1일 오후에 초기화됩니다.
- **구글 무료 번역 (비공식):** 계정·API 키 없이 인터넷 연결만으로 사용합니다. 공개 API가 아닌 비공식 방식이라 요청 제한·실패가 발생할 수 있습니다.
- **Bing 무료 번역 (비공식):** 계정·키 없이 사용합니다. 비공식 방식이라 언제든 차단될 수 있으며, 실패한 채팅은 구글 무료 번역으로 대신 번역합니다.
- **파파고 무료 번역 (비공식):** 계정·키 없이 네이버 파파고 웹사이트로 번역하며 한국어 구어체에 강합니다. 비공식 방식이라 언제든 차단될 수 있습니다. 실패한 채팅, 파파고가 지원하지 않는 언어, 파파고가 언어를 확실히 판별하지 못한 채팅은 구글 무료 번역으로 대신 번역합니다.
- **크롬 내장 번역 (무료 · PC 안에서 번역):** PC에 설치된 크롬(138 이상)의 번역 모델로 이 PC 안에서 번역합니다. **번역할 채팅과 번역 결과는 이 PC 안에서만 처리되며 외부 서버로 전송되지 않습니다.** 앱과 크롬 창은 이 PC 안에서만 접속되는 연결(localhost)로 주고받으며, 인터넷은 언어팩을 처음 받을 때만 사용합니다. 무료이고 사용 한도가 없습니다. 번역을 시작하면 크롬 창(ZM 크롬 번역 연결)이 열리고, 번역이 되면 저절로 최소화됩니다. 이 창을 닫으면 번역이 멈춥니다. 언어마다 언어팩(약 80MB)을 한 번 받아야 하며, 크롬 정책상 크롬 창 안에서 직접 **받기**를 눌러야 합니다. 언어팩이 없는 언어의 채팅은 번역되지 않고 작업 표시줄의 크롬 창이 깜빡입니다. 미리 받아 두려면 **크롬 번역 창 열기**를 누르세요. 은어·게임 말투 번역은 구글 클라우드 번역보다 약합니다.
- **Microsoft 번역 (Azure):** Bing과 같은 엔진의 공식 API입니다. 다른 엔진보다 설정이 복잡하며 Azure 가입(카드 본인 확인), Translator 리소스 만들기, 키·지역 복사 등 여러 단계가 필요합니다. 처음이라면 구글 클라우드 번역이나 Bing 무료 번역이 더 간단합니다. 키 입력칸 옆 **API 키 발급하기**의 안내에 따라 Translator 리소스를 **Free F0** 계층으로 만들고 키와 지역을 입력하세요. 매달 200만 자까지 무료이며, 한도를 모두 사용하면 요금 없이 해당 월의 번역이 중지됩니다.
- 구글 무료 번역은 같은 언어의 채팅을 최대 16줄씩 묶어 보내며, 실패하면 다른 구글 주소로 다시 번역합니다.
- 일반 번역은 문장 단위로 번역하며 이전 대화·추가 번역 지침·문맥 조건 용어를 적용하지 않습니다. 대신 용어집의 **번역 전 바꾸기** 규칙으로 게임 약어(`omw`, `mb`, `vic` 등)를 풀어서 전송합니다.

### AI 번역
앞뒤 대화와 게임 설명·용어를 이해해 은어와 말투를 살리지만, 일반 번역보다 느리고 계정·키·서버가 필요합니다.
- **무료 키로 체험:** AI 번역을 선택하면 표시되는 **시작하기** 버튼을 누르세요(설정 마법사와 번역 탭에 모두 있습니다). 별도 창에서 **Google Gemini 3.8 Flash(추천)** 또는 **Groq**를 선택하고 ① 키 발급 페이지 열기 → ② 키 붙여넣기 → ③ **연결 확인**을 진행합니다. 모델 선택과 예문 번역까지 자동으로 확인합니다.
  - 무료 사용량이 적어 **채팅이 많은 게임에서는 도중에 한도에 도달해** 번역이 실패할 수 있습니다. 한도를 초과하면 오류 문구로 알려 드립니다.
  - Gemini 무료 등급에서는 전송한 채팅과 번역 결과가 Google 서비스 개선에 사용되며 사람이 검토할 수 있습니다.
- **클라우드 API:** OpenAI·Gemini·DeepSeek·OpenRouter·Groq·Azure 프리셋을 누르고 모델 ID와 본인 API 키를 입력합니다. 요금은 각 서비스 기준입니다.
- **Codex:** [공식 CLI 설치 안내](https://learn.chatgpt.com/docs/codex/cli)에서 **Windows**를 선택해 설치하고, Windows PowerShell에서 `codex login`으로 로그인합니다. `codex login status`로 상태를 확인할 수 있습니다. 앱에서 **Codex 자동 찾기**를 누르세요. ChatGPT 앱·Codex 설치판·npm·VS Code 확장 등에 포함된 Codex를 모두 찾아 **가장 최신 버전**을 사용하며, 사용 중인 버전과 설치 위치를 표시합니다. 자동 찾기에 실패하면 **찾아보기**에서 Windows용 `codex.exe`를 지정합니다(`codex.cmd`나 WSL 내부 파일은 제외). ChatGPT 계정 한도가 적용되며 응답이 API보다 느립니다. 사용한 모델을 제보에 적어 주세요.
- **Claude (계정 로그인):** Anthropic 안내에 따라 Claude Code를 설치하고, Windows PowerShell에서 `claude`를 실행해 로그인합니다. 앱에서 **Claude Code 자동 찾기**를 누르면 설치된 Claude Code를 모두 찾아 **가장 최신 버전**을 사용하며, 로그인 상태와 요금제 종류, 선택할 수 있는 모델 목록을 표시합니다. 번역 모델은 **Sonnet(번역 추천)**을 권장하며, Haiku는 요금제 한도를 적게 사용합니다. 자동 찾기에 실패하면 **찾아보기**에서 `claude.exe`를 지정합니다. 사용량은 본인의 Claude 요금제(Pro·Max) 한도에서 차감되며, 게임 채팅을 장시간 번역하면 한도가 빠르게 소진될 수 있습니다. 앱은 Claude 계정 정보를 읽거나 저장하지 않습니다. Anthropic 약관과 정책에 따라 이 방식이 제한되거나 변경될 수 있습니다.
- **로컬 모델:** 실행 중인 OpenAI 호환 서버(Ollama, LM Studio)의 주소와 로드된 모델이 필요합니다. 서버는 ZIP에 포함되어 있지 않습니다.

연결은 **로그·진단 → 진단 · 테스트 → 선택한 엔진으로 번역** 또는 마법사의 **연결 테스트**로 확인합니다. 프로그램에 번역 계정이나 사용료는 포함되어 있지 않습니다.

## 게임 설정

- **프리셋:** 제어판 상단의 프리셋 목록에서 게임에 맞는 프리셋을 선택합니다. WarDogs는 **WarDogs** 프리셋을 선택하면 채널 인식, 팀 색상, 상자 표시 제외, WarDogs 용어가 함께 적용됩니다. 다른 게임은 **게임** 탭에서 **새 프리셋**을 만들거나 '기본' 프리셋을 사용하세요. 프리셋 복제·삭제도 **게임** 탭에서 할 수 있습니다.
- **채팅 영역에 게임이 아닌 창이 보이면 읽기를 일시 중지합니다(기본 켜짐).** 번역을 시작할 때 활성화되어 있던 프로그램을 게임으로 인식하고, 읽기 전후로 채팅 영역에 그 프로그램의 창이 표시되는지 확인합니다. 다른 모니터의 창은 영향을 주지 않습니다. **게임 → 채팅 영역과 게임 창**에서 끄거나 게임 프로그램을 직접 선택할 수 있습니다(게임으로 판단되는 프로그램은 ★로 먼저 표시). 끄면 채팅 영역에 표시되는 다른 앱의 글자도 번역 서비스로 전송됩니다. 게임을 하지 않을 때는 번역을 중지하세요.
- **채팅 영역 설정:** 채널·닉네임·본문 전체와 위아래 여백을 포함하세요. 해상도·화면 배율·게임 창 위치를 변경하면 영역을 다시 확인하세요.
- **게임을 종료하면:** 같은 게임 프로그램을 다시 켤 때까지 채팅 읽기를 멈추고 제어판에 안내를 표시합니다.
- **인식 보정:** **게임 → 인식 보정 → 인식 보정 열기**에서 채팅 영역을 캡처해 보여 줍니다. 채팅 탭·아이콘·입력 줄처럼 채팅이 아닌 부분은 드래그해 **제외 영역**으로 지정합니다. 배경이 비치는 채팅창은 글자 획을 클릭해 **글자 색**을 고르면 그 색과 비슷한 글자만 읽습니다. **인식 테스트**로 번역 요청 없이 결과를 확인할 수 있습니다. 게임 글꼴에서 자주 잘못 읽히는 글자(예: `0` → `O`, 닉네임 `망기적` → `밍기적`)는 표의 **OCR 교정 사전**에 등록하세요. 모두 프리셋별로 저장됩니다.
- **프리셋 내보내기·가져오기:** **게임 → 프리셋**에서 현재 프리셋의 설정과 전용 용어·상용구를 `.zmpreset.json` 파일로 저장하거나 불러옵니다. API 키·경로·월 상한과 공통 용어는 넣지 않습니다. 가져온 파일은 새 프리셋으로 추가됩니다.
- **팀 색상 (WarDogs):** 채팅 줄 왼쪽의 진영 표지(그린 ●, 레드 ▼, 블루 ■) 색상을 인식해 번역창의 닉네임을 같은 색으로 표시합니다. **채팅 영역에 표지까지 포함**해야 하며, 표지를 찾지 못한 줄은 흰색으로 표시합니다.
- **상자 표시 제외 (WarDogs):** 상자 위에 표시되는 `OWNER: 이름`·`상자 내구도`를 채팅으로 인식하지 않습니다. WarDogs 프리셋에서는 기본으로 켜져 있습니다.
- **글자 인식:** 기본은 내장 OCR입니다. 다른 언어를 인식하려면 **앱 설정 → 고급 · Windows OCR 호환 모드**를 선택하고 해당 언어팩을 설치한 뒤 사용할 언어를 선택하고 **저장·적용**하세요. 지원 범위는 Windows OCR에서 제공하는 언어에 따릅니다.
- **용어집:** **용어집·상용구** 탭에 게임 약어·핵쟁이 같은 공통 용어와 WarDogs 프리셋 전용 용어(FOB·핫존·컨트롤 존·자주포 등)가 포함되어 있습니다. 용어마다 **공통 · 전체** 또는 특정 프리셋 전용으로 적용 범위를 정할 수 있으며, 목록에는 현재 프리셋에 적용되는 항목만 표시됩니다. 검색 칸과 처리 방식 필터로 찾아 수정·해제·삭제할 수 있습니다. 처리 방식은 **원문 유지**(FOB처럼 그대로 유지), **번역 고정**(cheater → 핵쟁이), **문맥 조건**(AI 번역 전용), **번역 전 바꾸기**(일반 번역으로 보내기 전에 약어를 풀어 씀)입니다.
- **화면 캡처·방송에서 번역창 숨기기:** **앱 설정 → 화면 캡처·방송**에서 켜면 스크린샷·녹화·디스코드/OBS 화면 공유에 번역창과 내 채팅 번역 입력 창이 표시되지 않고 내 화면에만 표시됩니다(기본 꺼짐). 이 Windows 기능을 지원하지 않는 일부 캡처 프로그램에서는 표시될 수 있습니다.
- **화면 글자 한 번 번역:** **Ctrl+Alt+R**(또는 **실시간 번역** 탭의 버튼)을 누른 뒤 화면의 글자를 드래그하면 그 부분만 읽어 번역하고 옆에 표시합니다. 번역 중이 아니어도 동작하며, 현재 프리셋의 번역 엔진·용어집을 사용합니다. Esc나 다른 곳 클릭으로 닫습니다.
- **번역창 숨기기:** **Ctrl+Alt+H**를 누르면 번역은 계속하면서 번역창만 숨기고, 다시 누르면 표시합니다.
- **알림 영역 아이콘:** 작업 표시줄 알림 영역의 ZM 아이콘을 클릭하면 제어판이 열리고, 오른쪽 클릭 메뉴에서 번역 시작·중지, 번역창 숨기기, 화면 글자 한 번 번역, 종료를 할 수 있습니다. **앱 설정 → 알림 영역**에서 창을 닫거나 최소화하면 알림 영역으로 보내도록 설정할 수 있습니다(기본 꺼짐).
- **번역창:** 위치와 크기는 번역을 중지하고 **번역창** 탭에서 **번역창 잠금**을 해제한 뒤 조절합니다. 번역 중에는 클릭이 게임으로 전달됩니다. 채팅이 없을 때 빈 번역창이 보이지 않는 것은 정상입니다.
- 처음에는 창 모드 또는 테두리 없는 창 모드로 시험해 주세요. 게임마다 캡처·오버레이 동작과 외부 프로그램 관련 정책이 다를 수 있으며, 모든 게임에서 검증된 것은 아닙니다.

## 보이스챗 번역

게임 보이스챗을 Windows 11의 **라이브 캡션**으로 글자로 바꿔 번역합니다. 번역은 번역창에 채팅 번역과 함께 🎙 표시를 붙여 나옵니다.

1. **음성 번역** 탭에서 **보이스챗 번역 사용**을 켜고 **듣는 언어**를 고른 뒤 **저장·적용**합니다. 프리셋별로 저장되며 기본은 꺼짐입니다.
2. 번역을 시작하면 앱이 라이브 캡션을 고른 언어로 켜고, 창을 최소화해 작업 표시줄에서도 숨깁니다. 제어판 상태 줄의 🎙 줄에 진행 상황이 표시됩니다.
3. 문장이 끝나면(다음 문장이 시작되거나 말이 잠시 끊기면) 번역해 표시합니다.
4. 번역을 멈추면 라이브 캡션을 닫고 원래 듣는 언어와 창 위치로 되돌립니다.

- **필요 조건:** Windows 11 22H2 이상. 라이브 캡션이 없는 PC(Windows 10, Windows 11 21H2 등)에서는 **음성 번역** 탭의 설정이 비활성화되고 이유가 표시됩니다. 음성 번역이 켜진 프리셋을 이런 PC에서 쓰면 채팅만 번역합니다.
- **처음 쓰는 언어:** 라이브 캡션 창이 열려 개인 정보 동의나 음성 인식 팩 내려받기를 안내합니다. 안내에 따라 진행하면 창을 숨기고 듣기 시작합니다. 음성 인식 팩은 한 번만 받으면 됩니다.
- **지원 언어:** 영어(미국·영국 등), 중국어(간체·번체), 일본어, 한국어, 독일어, 프랑스어, 스페인어, 이탈리아어, 포르투갈어, 덴마크어 등. 러시아어는 라이브 캡션이 지원하지 않습니다. 영어·중국어·한국어·일본어는 목록 맨 위 **자주 쓰는 언어**에 있습니다. 라이브 캡션은 한 번에 한 언어만 들으므로 다른 언어로 말하면 엉뚱한 글자가 나오고 번역도 틀립니다.
- **이미 켜 둔 라이브 캡션:** 그 창을 그대로 쓰며 듣는 언어를 바꾸지 않고, 번역을 멈춰도 닫지 않습니다. 언어를 바꾸려면 라이브 캡션을 닫고 번역을 다시 시작하세요.
- **내 목소리:** 라이브 캡션 설정의 **마이크 오디오 포함**을 켜면 내 목소리도 번역됩니다. 앱이 켤 때는 꺼진 상태로 시작하며, 켜져 있으면 상태 줄에 알립니다.
- **게임 창이 앞에 없을 때:** 채팅 읽기는 일시 중지되지만 보이스챗 번역은 계속됩니다.
- 누가 말했는지는 구분하지 않습니다. 여러 사람이 동시에 말하거나 게임 소리가 크면 인식이 틀릴 수 있습니다.
- 음성 인식은 라이브 캡션이 PC 안에서 하며 소리는 밖으로 보내지 않습니다. 들은 문장은 화면 채팅과 같은 번역 엔진·용어집으로 번역하고, 구글 클라우드 번역을 쓰면 월 상한에 포함됩니다.
- 라이브 캡션이 닫히면 두 번까지 다시 켜고, 그래도 닫히면 음성 번역만 멈춥니다. 채팅 번역은 계속됩니다.

## 내 채팅 번역

번역 중 게임에서 **Shift+Enter**를 누르면 입력 창이 표시됩니다. 한국어로 입력하고 **Enter**를 누르면 선택한 언어로 번역해 클립보드에 복사하므로, 게임 채팅에서 **Ctrl+V**로 붙여 넣으세요. **↑/↓**로 언어를 변경하고 **Esc**로 닫습니다.

- 단축키는 번역 중 게임 창이 활성화되어 있을 때만 동작합니다. 메신저·브라우저 등 다른 프로그램에서는 기존 Shift+Enter 동작(줄바꿈 등)이 그대로 유지됩니다.
- **내 채팅 번역** 탭에서 번역할 언어·기본 언어·번역 확인 후 복사·입력 창 모양을 설정합니다. 이 설정은 프리셋마다 저장됩니다.
- **게임 채팅 글자 수 제한:** 번역이 게임 채팅 칸에 들어가는 글자 수(WarDogs 프리셋 64자, 0이면 제한 없음)보다 길면 문장·쉼표·띄어쓰기 단위로 나눠 `(1/3) …`처럼 먼저 보여 줍니다. Enter로 첫 부분을 복사해 붙여 넣어 보낸 뒤 단축키를 다시 누르면 다음 부분이 나옵니다. 새로 입력하거나 Esc를 누르면 남은 부분은 취소됩니다.
- **용어집 적용:** 용어집의 한국어 용어는 번역할 언어에 맞는 표기로 바뀝니다(예: '자주포' → 영어 `PZH`, 중국어 `攀枝花`). 맞는 표기가 없으면 번역 엔진에 맡깁니다.
- **입력 창 위치:** 화면 중앙(기본, 가운데보다 조금 아래) · 채팅 영역 근처 · 커스텀 위치 중에서 선택합니다. 커스텀 위치는 **위치 정하기**를 눌러 표시된 입력 창의 제목줄을 원하는 곳으로 끌어 두면 저장됩니다.
- 단축키는 **앱 설정** 탭에서 변경합니다. 게임에 자동으로 입력하지는 않습니다.

## 로그와 제보

예기치 않게 종료되면 채팅·닉네임·API 키·오류 메시지 원문을 제외한 오류 종류, 발생 위치, 시각, 앱 버전만 `%APPDATA%\ZMGameChatTranslator\errors\last-error.json`에 최근 1건 보관합니다. 자동으로 전송하지 않습니다.

기본값은 **세션 로그 자동 기록 꺼짐 / 채팅 내용 포함 꺼짐**입니다. 기본 상태에서는 제보 양식에 문제와 발생 시각을 적어 알려 주세요. 파일 기록이 꺼진 세션은 문제 표시·분석·ZIP 내보내기용 파일을 만들지 않습니다.

조사에 로그가 필요하면 **로그·진단 → 세션 로그 자동 기록**을 켜고 **저장·적용**한 다음 새 세션을 시작합니다. 원문·번역문·닉네임·OCR 원문·메모까지 필요할 때만 **내용 포함**도 켜세요.

로그를 켠 세션에서는 **실시간 번역** 탭에서 문제 행을 선택하고 메모를 입력한 뒤 **OCR 오류 / 오역 / 중복**을 누릅니다. **채팅 누락**은 행을 선택하지 않고 표시합니다. 플레이 후 **번역 중지 → 로그·진단 → 목록 새로고침 → 세션 선택 → 로그 분석 → 선택 세션 ZIP 내보내기**로 해당 세션을 내보냅니다. ZIP은 자동 업로드되지 않습니다. 내용을 확인한 뒤 프로그램을 전달한 개발자에게 개인적으로 전달하세요. 공개 게시판에 원본 로그를 올리지 마세요.

번역을 위해 채팅 텍스트(AI 번역은 화자·채널·주변 문맥·용어집 포함)를 선택한 서비스로 전송합니다. OCR은 이 PC에서 처리하며 화면 이미지는 전송하지 않습니다. 내용 로그를 끄는 것과 번역 서비스로 전송하는 것은 별개입니다. 보이스챗 번역의 음성 문장과 번역은 내용 포함을 켜도 로그에 남기지 않습니다(건수와 처리 시간만 기록).

문제 제보에는 [양식](BUG-REPORT.md)을 사용하세요. API 키, `settings.json`, Codex 인증 폴더는 필요하지 않습니다. 화면을 첨부한다면 다른 앱과 개인 정보를 가려 주세요.

## 업데이트·되돌리기·삭제

- **업데이트:** 새 버전이 공개되면 앱 상단에 안내가 표시됩니다. **다운로드 페이지 열기**로 새 ZIP 파일을 받으세요(자동으로 설치하지 않습니다). 앱을 종료하고 새 ZIP 파일을 **새 폴더**에 압축 해제합니다. 이전 버전과 동시에 실행하지 마세요. 설정은 `%APPDATA%\ZMGameChatTranslator\settings.json`에 저장되어 그대로 유지됩니다. 기존 설정이 있으면 설정 마법사는 자동으로 열리지 않습니다.
- **되돌리기:** 앱을 종료하고 보관한 이전 버전 실행 파일을 실행합니다. 업데이트 전에 설정 파일을 개인 보관용으로 복사해 두면 복구에 도움이 됩니다. 설정 파일은 다른 사람에게 보내지 마세요.
- **앱 삭제:** 종료 후 압축을 풀었던 프로그램 폴더를 삭제합니다. 설정·로그·구글 클라우드 사용량 기록(`google-cloud-usage.json`)은 `%APPDATA%\ZMGameChatTranslator`에 남으므로, 필요 없다면 직접 삭제하세요. `%LOCALAPPDATA%\ZMGameChatTranslator`에는 Codex 조회·요청용 임시 자료가 남을 수 있습니다.
- **로그 보관:** 새 세션을 시작할 때 오래된 세션부터 자동으로 삭제해 보관 범위(기본 20개·256MB) 안으로 맞춥니다. 보관할 세션 수와 최대 용량은 **로그·진단** 탭에서 변경할 수 있습니다. 필요한 세션은 미리 ZIP으로 내보내세요. 한 세션의 기록이 32MB에 도달하면 해당 세션의 파일 기록만 중지합니다.
- **실행 차단:** 서명되지 않은 배포판입니다.
  - "Windows의 PC 보호" 경고는 `SHA256SUMS.txt`로 받은 ZIP이 맞는지 확인한 뒤 **추가 정보 → 실행**으로 열 수 있습니다.
  - **스마트 앱 컨트롤(SAC) 차단:** 받은 파일과 배포자를 신뢰하고 설정 변경에 동의한다면 **Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정 → 끄기**를 선택하고, 상태를 확인한 뒤 앱을 다시 실행할 수 있습니다. 이 앱만 허용하는 기능은 없으며 **PC 전체의 SAC 보호가 꺼집니다.** Defender 실시간 보호는 켜 두세요.
  - 변경 전 Windows 업데이트와 설정 화면의 재활성화 안내를 확인하세요. 최신 업데이트에서는 SAC를 다시 켤 수 있지만, 이전 버전에서는 Windows 초기화·재설치가 필요할 수 있습니다. 다시 켜면 앱이 다시 차단될 수 있습니다. 변경을 원하지 않거나 설정이 없거나 계속 차단되면 경고 문구와 Windows 버전을 제보해 주세요. 단계별 안내는 ZIP 루트의 **START-HERE.txt**에 있습니다.
