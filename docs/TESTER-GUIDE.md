# 지인 테스트 안내 · 0.4.30

처음에는 ZIP 안의 **START-HERE.txt** 순서대로 진행하세요. 처음 실행하면 **설정 마법사**가 열리고, 제어판 위쪽 **설정 마법사** 버튼으로 언제든 다시 열 수 있습니다. 테스트는 한 번에 20~30분, 가능하면 서로 다른 날 두 번을 부탁드립니다. 설정이 막히면 그 지점까지의 피드백만 보내도 도움이 됩니다.

Windows x64용이며 .NET 런타임과 글자 인식(OCR) 모델이 포함되어 있습니다. **Windows OCR 언어팩은 필요하지 않습니다.** 실행 파일 옆의 `models` 폴더를 함께 보관하세요. 최소 대상은 Windows 10 2004 이상이고 현재 검증은 Windows 11에서 진행했습니다. 다른 PC의 최초 실행, 화면 배율, 게임별 호환성은 이번 테스트로 확인합니다. macOS/Linux/ARM64용 배포본은 없습니다.

## 번역 엔진 고르기

**연결 설정**(또는 마법사 1단계)에서 먼저 **일반 번역**과 **AI 번역** 중 하나를 고르고, 그 안에서 엔진을 고릅니다. 선택한 엔진에 필요한 항목만 표시됩니다.

### 일반 번역
- **구글 무료 번역 (기본):** 계정·API 키 없이 인터넷 연결만으로 사용합니다. 비공식 무료 연결이라 요청 제한·실패가 생길 수 있습니다.
- **구글 클라우드 번역:** 본인 Google Cloud API 키로 번역합니다. **매달 50만 자까지 무료**이고, 넘으면 100만 자당 약 $20입니다(원문 글자만 계산). 무료 한도만 쓰더라도 결제 계정(카드) 등록이 필요합니다.
  - 마법사가 발급 단계를 차례로 안내합니다: 프로젝트 → 결제 연결 → API 사용 → API 키 → 붙여넣기 → 연결 확인. 실패하면 어느 단계를 고칠지 알려 줍니다.
  - **월 상한:** 기본 450,000자입니다. 상한에 닿으면 Google로 보내지 않고 번역 실패로 표시합니다. 이 PC에서 보낸 글자만 세므로, 같은 키를 다른 곳에서도 쓰면 여유를 두세요. 월은 미국 태평양 시간 기준이라 한국 시간 매월 1일 오후에 초기화됩니다.
- 일반 번역은 문장 단위로 번역하며 이전 대화·추가 번역 지침·문맥 조건 용어를 적용하지 않습니다.

### AI 번역
앞뒤 대화와 게임 설명·용어를 이해해 은어와 말투를 살리지만, 일반 번역보다 느리고 계정·키·서버가 필요합니다.
- **무료로 시작하기:** AI 번역을 고르면 나오는 **무료로 시작하기** 버튼을 누르세요(마법사와 연결 설정 모두에 있습니다). 별도 창에서 **Google Gemini 3.8 Flash(추천)** 또는 **Groq**를 고르고 ① 키 발급 페이지 열기 → ② 키 붙여넣기 → ③ **연결 확인**을 누릅니다. 모델 선택과 예문 번역까지 자동으로 확인합니다.
  - 무료 사용량이 적어 **채팅이 많은 게임에서는 도중에 한도에 걸려** 번역이 실패할 수 있습니다. 한도 초과면 오류 문구로 알려 줍니다.
  - Gemini 무료 등급에서는 보낸 채팅과 번역 결과가 Google 서비스 개선에 쓰이고 사람이 검토할 수 있습니다.
- **클라우드 API:** OpenAI·Gemini·DeepSeek·OpenRouter·Groq·Azure 프리셋을 누르고 모델 ID와 본인 API 키를 입력합니다. 요금은 각 서비스 기준입니다.
- **Codex:** [공식 CLI 설치 안내](https://learn.chatgpt.com/docs/codex/cli)에서 **Windows**를 골라 설치하고, Windows PowerShell에서 `codex login`으로 로그인합니다. `codex login status`로 확인할 수 있습니다. 앱에서 **Codex 자동 찾기**를 누르세요. 자동 찾기에 실패하면 **찾아보기**에서 Windows용 `codex.exe`를 지정합니다(`codex.cmd`나 WSL 내부 파일은 제외). ChatGPT 계정 한도가 적용되고, 응답이 API보다 느립니다. 사용한 모델을 제보에 적어 주세요.
- **로컬 모델:** 실행 중인 OpenAI 호환 서버(Ollama, LM Studio)의 주소와 로드된 모델이 필요합니다. 서버는 ZIP에 포함되지 않습니다.

연결은 **진단 · 테스트 → 선택한 엔진으로 번역** 또는 마법사의 **연결 테스트**로 확인합니다. 프로그램에 번역 계정이나 사용료가 포함되지는 않습니다.

## 게임 설정

- **게임 프로필:** WarDogs라면 **WarDogs 프리셋 적용**을 누르면 채널 인식과 팀 색상이 한 번에 설정됩니다.
- **번역 중에는 다른 창으로 전환해도 지정한 화면 영역을 계속 읽습니다.** 그 자리에 다른 앱이 보이면 그 글자도 번역 서비스로 전송됩니다. 게임을 하지 않을 때는 번역을 중지하세요.
- **채팅 영역 설정:** 채널·닉네임·본문 전체와 위아래 여백을 포함하세요. 해상도·화면 배율·게임 창 위치를 바꾸면 영역을 다시 확인합니다.
- **팀 색상 (WarDogs):** 채팅 줄 왼쪽의 진영 표지(그린 ●, 레드 ▼, 블루 ■) 색을 읽어 번역창의 닉네임을 같은 색으로 표시합니다. **채팅 영역에 표지까지 포함**해야 하며, 표지를 찾지 못한 줄은 흰색입니다.
- **OCR 설정 탭:** 기본은 내장 OCR입니다. **고급 · Windows OCR 호환 모드**는 비교용이며 이때만 Windows 언어팩이 필요합니다.
- **번역창:** 위치와 크기는 **번역 중지 → 번역창 잠금 해제** 후 조절합니다. 번역 중에는 클릭이 게임으로 통과합니다. 채팅이 없을 때 빈 번역창이 보이지 않는 것은 정상입니다.
- 처음에는 창 모드 또는 테두리 없는 창 모드로 시험해 주세요. 게임마다 캡처·오버레이 동작과 외부 프로그램 관련 정책이 다를 수 있으며 모든 게임에서 검증된 것은 아닙니다.

## 꼭 확인할 다섯 가지

1. 외국어가 자연스럽게 번역되는지, 한국어 채팅이 영어처럼 잘못 읽히지 않는지 봅니다. 한국어는 기본적으로 번역 요청을 생략하므로 **원문**부터 확인합니다.
2. 같은 채팅이 여러 번 번역되지 않는지 확인합니다. 스크롤하거나 채팅창을 닫았다 열 때, 두 줄로 넘어가는 긴 채팅도 봐 주세요. 새로 보낸 같은 문장은 별도 메시지가 맞습니다.
3. WarDogs라면 닉네임 색이 게임의 진영 표지와 같은지 확인합니다.
4. 다른 창으로 전환했을 때 무엇이 번역되는지 확인합니다. 번역 중지를 잊었을 때 어떤 글자가 잡히는지 알려 주세요.
5. 느리거나 누락된 채팅, 프로그램 종료, 게임 성능 저하, 재실행 후 설정 유지를 기록합니다. 대략적인 시각을 함께 적어 주세요.

## 로그와 제보

기본값은 **세션 로그 자동 기록 꺼짐 / 채팅 내용 포함 꺼짐**입니다. 기본 상태에서는 제보 양식으로 문제와 발생 시각을 알려 주세요. 파일 기록이 꺼진 세션은 문제 표시·분석·ZIP 내보내기용 파일을 만들지 않습니다.

조사에 로그가 필요하면 **실사용 로그 → 세션 로그 자동 기록**을 켜고 **저장·적용**한 다음 새 세션을 시작합니다. 원문·번역문·닉네임·OCR 원문·메모까지 필요할 때만 **내용 포함**도 켜세요.

로그를 켠 세션에서는 문제 행을 고르고 메모를 입력한 뒤 **OCR 오류 / 오역 / 중복**을 누릅니다. **채팅 누락**은 행을 선택하지 않고 표시합니다. 플레이 후 **번역 중지 → 목록 새로고침 → 세션 선택 → 로그 분석 → 선택 세션 ZIP 내보내기**로 해당 세션을 내보냅니다. ZIP은 자동 업로드되지 않습니다. 내용을 확인한 뒤 프로그램을 전달한 개발자에게 개인적으로 보내세요. 공개 게시판에 원본 로그를 올리지 마세요.

번역을 위해 채팅 텍스트(AI 번역은 화자·채널·주변 문맥·용어집 포함)를 선택한 서비스로 보냅니다. OCR은 이 PC에서 처리하고 화면 이미지는 보내지 않습니다. 내용 로그를 끄는 것과 번역 서비스로 보내는 것은 별개입니다.

문제 제보에는 [양식](BUG-REPORT.md)을 사용하세요. API 키, `settings.json`, Codex 인증 폴더는 필요하지 않습니다. 화면을 첨부한다면 다른 앱과 개인 정보를 가려 주세요.

## 업데이트·되돌리기·삭제

- **업데이트:** 앱을 종료하고 새 ZIP을 **새 폴더**에 풉니다. 이전 버전과 동시에 실행하지 마세요. 설정은 `%APPDATA%\ZMGameChatTranslator\settings.json`에 있어 이어서 사용됩니다. 기존 설정이 있으면 설정 마법사는 자동으로 열리지 않습니다.
- **되돌리기:** 앱을 종료하고 보관한 이전 버전 실행 파일을 실행합니다. 업데이트 전에 설정 파일을 개인 보관용으로 복사해 두면 복구에 도움이 됩니다. 설정 파일은 다른 사람에게 보내지 마세요.
- **앱 삭제:** 종료 후 압축을 풀었던 프로그램 폴더를 삭제합니다. 설정·로그·구글 클라우드 사용량 기록(`google-cloud-usage.json`)은 `%APPDATA%\ZMGameChatTranslator`에 남으니, 필요 없을 때 직접 삭제하세요. `%LOCALAPPDATA%\ZMGameChatTranslator`에는 Codex 조회·요청용 임시 자료가 남을 수 있습니다.
- **로그 보관:** 새 세션을 시작할 때 오래된 세션부터 자동으로 삭제해 보관 범위(기본 20개·256MB) 안으로 맞춥니다. 보관할 세션 수와 최대 용량은 **실사용 로그** 탭에서 바꿀 수 있습니다. 필요한 세션은 미리 ZIP으로 내보내세요. 한 세션의 기록이 32MB에 닿으면 그 세션의 파일 기록만 멈춥니다.
- **실행 차단:** 서명되지 않은 테스트판입니다.
  - "Windows의 PC 보호" 경고는 `SHA256SUMS.txt`로 받은 ZIP이 맞는지 확인한 뒤 **추가 정보 → 실행**으로 열 수 있습니다.
  - **스마트 앱 컨트롤(SAC) 차단:** 받은 파일과 배포자를 신뢰하고 설정 변경에 동의한다면 **Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정 → 끄기**를 선택하고, 상태를 확인한 뒤 앱을 다시 실행할 수 있습니다. 이 앱만 허용하는 기능은 없으며 **PC 전체의 SAC 보호가 꺼집니다.** Defender 실시간 보호는 켜 두세요.
  - 변경 전 Windows 업데이트와 설정 화면의 재활성화 안내를 확인하세요. 최신 업데이트에서는 SAC를 다시 켤 수 있지만, 이전 버전에서는 Windows 초기화·재설치가 필요할 수 있습니다. 다시 켜면 앱이 재차 차단될 수 있습니다. 변경을 원하지 않거나 설정이 없거나 계속 차단되면 경고 문구와 Windows 버전을 제보해 주세요. 단계별 안내는 ZIP 루트의 **START-HERE.txt**에 있습니다.
