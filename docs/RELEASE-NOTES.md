# 0.4.30 공개 배포판

앱 버전은 0.4.30이며, ZIP의 배포 번호는 `release-manifest.json`의 `release`에 기록합니다. 배포 문서·의존성 고지·파일별 SHA-256 목록을 포함한 Windows x64용 패키지입니다.

## 이번 판의 변경 (0.4.30)

- `C4 2명`과 `C42명`처럼 공백이 흔들릴 때 같은 채팅을 중복 처리하는 문제를 개선했습니다.
- 스크롤 중 상단에서 일부 잘린 오래된 줄을 새 채팅으로 번역하는 문제를 줄였습니다.
- 한국어 짧은 채팅 끝의 `ㄱ/7`을 재인식하고 획 모양을 확인해 반복 자음을 보완합니다. `행님ㄱㄱ`은 합성 이미지에서 검증했으며 실제 게임의 다양한 글꼴에서는 추가 확인이 필요합니다.
- 한국어·저장 상용구·문장부호는 외부 번역 요청이 끝날 때까지 기다리지 않고 표시합니다.
- 실행이 SAC에 차단될 때 사용자가 직접 설정을 변경하는 방법과 적용 범위를 시작 안내에 추가했습니다.

## 이전 변경 (0.4.26 ~ 0.4.29)

- **게임 글꼴의 한글 닉네임이 통째로 빠지던 문제를 줄였습니다(0.4.29).** 닉네임이 `[팀]:`처럼 비어 버리면 한국어 모델의 판독을 조금 낮은 확신에서도 받아들입니다. 글꼴에 따라 비슷한 글자로 읽힐 수 있습니다(예: `렛삐` → `켓삐`). 그래도 매번 같은 이름으로 읽혀서 같은 채팅이 반복 번역되지 않습니다.
- **한글 닉네임이 한자로 바뀌거나 사라지던 문제를 고쳤습니다(0.4.28).** 닉네임 구간을 한국어 모델로 다시 읽고, 기본 모델이 한자·가나로 읽었거나 놓친 경우에만 교체합니다. 영문·숫자 닉네임은 그대로이며, 닉네임이 흔들려 같은 채팅이 다시 번역되는 일도 줄어듭니다. 한 글자 한글 닉네임은 대상에서 제외했습니다.
- **무료 AI 번역 안내를 별도 창으로 분리하고 Google Gemini 3.8 Flash를 1순위 추천으로 바꿨습니다(0.4.27).**
- 채팅이 화면에 뜨는 동안 닉네임이 한 글자씩 채워지거나 본문이 짧게 읽혀도 같은 채팅으로 인식합니다. 실사용 로그에서 같은 채팅이 여러 번 번역되던 주된 원인이었습니다.
- 아직 이름만 뜬 다음 채팅이 앞 채팅 뒤에 붙지 않습니다.
- **다른 창으로 전환하면 수집을 멈추던 기능을 제거했습니다.** 이제 번역 중에는 창 전환과 상관없이 지정한 화면 영역을 계속 읽습니다. 게임을 하지 않을 때는 번역을 중지하세요.
- 로그 폴더가 가득 차 기록이 멈추지 않도록, 새 세션을 시작할 때 오래된 세션부터 자동으로 삭제합니다(기본 20개·256MB, 실사용 로그 탭에서 변경).

## 처음 사용과 설정

- **설정 마법사:** 처음 실행하면 번역 엔진 → 게임 → 채팅 영역 → 번역창·단축키 순서로 안내합니다. 엔진별 키·주소도 마법사에서 바로 입력하고 연결을 확인합니다.
- **무료 AI 번역 안내:** AI 번역을 고르면 **무료로 시작하기** 버튼이 나옵니다. 버튼을 누르면 별도 창에서 **Google Gemini 3.8 Flash(추천)** 또는 Groq의 키 발급 → 붙여넣기 → 연결 확인을 안내합니다. 연결 확인은 정식 모델을 자동으로 고르고 예문을 번역해 봅니다.
- **구글 클라우드 번역 (권장):** 키 발급 단계를 안내하고, 무료 한도(월 50만 자)를 넘지 않도록 **월 글자 수 상한(기본 45만 자)**을 둡니다. 사용량은 연결 설정에 표시됩니다.
- **설정 화면 정리:**
  - 번역 엔진을 AI 번역과 일반 번역으로 나눠 고르고, 선택한 엔진에 필요 없는 항목은 숨깁니다.
  - OCR 설정은 별도 탭으로 옮겼습니다.
  - 탭 순서는 실시간 번역 → 게임 프로필 → 연결 설정 → OCR 설정입니다.

## 인식과 번역

- **내장 OCR:** Windows OCR 언어팩 설치 없이 영어·중국어를 읽고, 한국어 모델로 채널과 한국어 본문을 보완합니다. 기존 Windows OCR은 OCR 설정 탭의 호환 모드로 남아 있습니다.
- **WarDogs 팀 색상:** 채팅 줄 왼쪽의 진영 표지 색을 읽어 번역창의 닉네임을 그린·레드·블루로 표시합니다. **WarDogs 프리셋**이 게임 창·채널 인식·팀 색상을 한 번에 설정합니다.
- **같은 채팅의 중복 번역 감소.** 실제 플레이 로그로 원인을 찾아 고쳤습니다.
  - 닉네임이 프레임마다 조금씩 다르게 읽히는 경우(`0`/`O`, `♥`/`❤` 등)
  - 캡처 영역 맨 위에서 잘린 줄
  - 두 줄 채팅 사이의 진영 표지 때문에 둘째 줄이 빠지는 경우
  - 채팅 아래의 게임 화면 글자
  - 광고 문구 인식의 흔들림
- 사용 한도 초과(HTTP 429)와 월 상한 도달을 오류 문구로 알려 줍니다.

## 알려진 제한

- 흐린 글자·작은 글꼴·페이드 효과·짧은 채팅·닉네임은 여전히 틀리거나 누락될 수 있습니다. OCR과 번역의 정확도를 보장하지 않습니다.
- 둘째 줄에 콜론(`:`)이 들어간 긴 채팅은 별도 메시지로 인식될 수 있습니다.
- 무료 AI(Groq·Gemini)와 구글 무료 번역은 사용량 제한이 있어, 채팅이 많으면 도중에 실패할 수 있습니다. 한도에 걸려도 다른 엔진으로 자동 전환하지 않습니다.
- 번역 중에는 다른 창으로 전환해도 지정한 영역을 계속 읽습니다. 그 자리에 다른 앱이 보이면 그 글자도 번역 서비스로 전송됩니다.
- 구글 클라우드 월 상한은 이 PC에서 보낸 글자만 셉니다. Google 집계와 조금 다를 수 있습니다.
- Groq·Gemini·구글 클라우드의 실제 키 연결과 번역은 이번 테스트에서 처음 확인합니다. 개발 환경에서는 가짜 응답으로만 검사했습니다.
- 번역 속도는 네트워크, 서비스·모델, 계정 한도에 따라 달라집니다. Codex는 요청당 몇 초가 걸립니다.
- Windows x64용입니다. Windows 10의 최소 대상 버전과 다른 PC·배율·게임 환경의 실제 호환성은 추가 테스트가 필요합니다.
- **디지털 서명이 없습니다.** SmartScreen 경고가 나오거나 스마트 앱 컨트롤(SAC)이 실행을 막을 수 있습니다. SAC 차단 시 사용자가 설정에서 직접 끄는 절차와 PC 전체에 미치는 영향, 재활성화 제한은 START-HERE.txt와 TESTER-GUIDE.md를 확인하세요. 설정 변경은 선택 사항입니다.
- 번역용 계정·API 키·로컬 모델은 포함하지 않습니다.

설정은 START-HERE.txt와 [TESTER-GUIDE.md](TESTER-GUIDE.md), 문제 제보는 [BUG-REPORT.md](BUG-REPORT.md)를 참고하세요.
