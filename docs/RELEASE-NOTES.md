# 1.0.1 공개 배포판

## 1.0.1에서 바뀐 점

- **내 채팅 번역:** 번역 중 게임에서 **Shift+Enter**를 누르면 입력 창이 뜹니다. 한국어로 입력하고 Enter를 누르면 선택한 언어로 번역해 클립보드에 넣으니, 게임 채팅에 **Ctrl+V**로 붙여 넣으세요. ↑/↓로 언어를 바꾸고, 결과 확인 후 복사·한국어로 되돌려 확인을 선택할 수 있습니다. 게임에 자동으로 입력하지 않습니다.
- **번역 엔진 추가:** **Bing 무료 번역(비공식)**과 **Microsoft 번역(Azure, 월 200만 자 무료)**을 고를 수 있습니다. Bing은 게임 말투와 중국어가 구글 무료보다 자연스러운 편이며, 실패하면 구글 무료로 대신 번역합니다. Microsoft 번역은 무료 등급(F0)이 한도를 넘으면 요금 없이 멈추지만 Azure 설정 단계가 많습니다.
- **무료 번역 속도:** 구글·Bing 무료 번역이 여러 채팅을 최대 3개씩 동시에 번역합니다.
- **번역창 사라짐 수정:** 번역 중 번역창이 게임 창 뒤로 가려지면 다시 위로 올립니다. 키보드 포커스는 가져오지 않습니다.
- **새 버전 알림:** 앱을 켤 때 새 버전이 있으면 위쪽에 알리고, 변경 내용을 앱 안에서 볼 수 있습니다. 자동으로 내려받지 않으며 진단 · 테스트 탭에서 끌 수 있습니다.
- **화면 정리:** 새 **내 채팅 번역** 탭을 추가하고, **연결 설정**을 **번역 설정**으로, **용어집·상용구**를 한 탭으로 합쳤습니다.

## 업데이트 방법

실행 중인 앱을 종료하고 새 ZIP을 새 폴더에 풀어 실행하세요. 설정·용어집·API 키는 그대로 이어집니다.

## 사용 시 참고

- 내 채팅 번역 단축키는 번역 중에만 등록되며, 그동안 다른 앱의 같은 조합(예: 메신저 줄바꿈)도 입력 창을 엽니다. 설정에서 바꿀 수 있습니다.
- 작거나 흐린 글자·빠른 스크롤에서는 채팅이 잘못 인식되거나 누락될 수 있습니다. 번역 속도와 품질은 선택한 서비스와 네트워크 상태에 따라 달라집니다.
- 번역 중에는 다른 창으로 전환해도 지정한 화면 영역을 계속 읽습니다. 게임을 하지 않을 때는 번역을 중지하세요.
