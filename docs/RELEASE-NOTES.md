# 1.0.0 공개 배포판

공개 배포는 **1.0.0**부터 시작합니다. 게임 화면의 채팅을 읽어 한국어 번역을 표시합니다.

## 안정성과 사용 편의

- 설정 마법사와 연결 설정의 AI 번역 버튼을 **체험하기**, 안내 창 제목을 **AI 번역 체험하기**로 정리했습니다.
- 다운로드 후 실행과 설정 마법사 이용 안내를 보강했습니다. 마법사는 프로그램 상단 버튼으로 다시 열 수 있습니다.

- 중복 실행 시 기존 창을 표시하며 설정의 외부 변경을 감지합니다.
- 손상된 설정을 백업에서 복구하고 잘못된 항목을 정리합니다.
- 구글 클라우드 사용량을 요청 전에 저장합니다. 집계 오류 시 요청을 중지하고 사용량 보정을 지원합니다.
- Windows OCR에서 러시아어·태국어 등 다른 문자 체계의 후보 선택을 개선했습니다.
- 번역 실행 중 설정과 OCR 엔진이 서로 다르게 적용되는 문제를 방지했습니다.
- 용어 검증 실패는 해당 문장만 실패 처리하고, 일시적인 통신 오류는 대기 후 새 채팅부터 계속합니다.

## 주요 기능

- 한글 닉네임 누락·오인식과 같은 채팅의 반복 번역을 줄였습니다.
- WarDogs 채널·진영별 닉네임 색상과 처음 사용 설정 마법사를 지원합니다.
- 내장 OCR과 Windows OCR을 선택할 수 있습니다. 다른 지원 언어는 Windows OCR 언어팩을 설치해 사용하세요.
- 구글 클라우드 번역에 월 사용량 상한을 추가했습니다.
- 로그가 보관 한도를 넘으면 오래된 기록부터 자동 정리합니다.

## 사용 시 참고

작거나 흐린 글자·빠른 스크롤에서는 채팅이 잘못 인식되거나 누락될 수 있습니다. 번역 속도와 품질은 선택한 서비스와 네트워크 상태에 따라 달라집니다.

번역 중에는 다른 창으로 전환해도 지정한 화면 영역을 계속 읽습니다. 게임을 하지 않을 때는 번역을 중지하세요.
