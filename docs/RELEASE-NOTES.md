# 1.0.4 공개 배포판

## 1.0.4에서 바뀐 점

- **광고·스팸 채팅 번역 제외:** 핵 판매 사이트, QQ 그룹 모집, 성인 사이트 광고처럼 사이트 주소·연락처와 판매 문구가 함께 있는 채팅은 번역하지 않고 번역창에서도 숨깁니다. 번역 요청을 보내지 않으므로 유료 번역 사용량도 줄어듭니다. "he is cheating", "挂", "举报"처럼 핵 이야기를 하는 일반 채팅은 그대로 번역합니다. 광고로 판단한 채팅은 실시간 번역 탭의 기록 목록에 남아 있어, 잘못 걸렀다면 선택해서 **다시 번역**할 수 있습니다. **번역 설정 → 번역 동작**에서 끄거나 번역창에 "광고로 판단해 번역하지 않음"으로 표시하게 바꿀 수 있습니다.
- **상자 소유자 표시 오인식 수정:** WarDogs에서 상자 위에 뜨는 `OWNER: 이름`·`상자 내구도` 표시가 채팅 영역에 겹치면 채팅으로 읽혀 닉네임이 번역되던 문제(예: LION → 사자)를 고쳤습니다.
- **Claude (계정 로그인) 엔진:** 직접 설치하고 로그인한 Claude Code로, API 키 없이 본인 Claude 요금제(Pro·Max) 한도 안에서 AI 번역을 할 수 있습니다. **번역 설정 → AI 번역 → Claude (계정 로그인)**을 고르고 **연결 확인**을 누르세요. 앱은 Claude 계정 정보를 다루지 않으며, 오래 번역하면 요금제 한도가 빨리 줄 수 있습니다.
- **성능 최적화:** 채팅 글자가 바뀌지 않았으면(뒤의 게임 화면만 움직이면) 글자 인식을 건너뛰고, 메모리 사용량을 약 300MB 줄였습니다. CPU가 부족할 때는 게임이 먼저 처리되도록 우선순위를 낮췄습니다.
- **앱 아이콘:** 프로그램 로고를 만들어 exe와 창·작업 표시줄 아이콘에 적용했습니다.

## 1.0.3에서 바뀐 점

- **번역창 반투명 배경 상자:** 번역창 뒤에 어두운 반투명 상자를 표시하는 옵션을 추가했습니다. 번역이 어디에 뜨는지 알기 쉽고, 밝은 화면에서도 글자가 잘 보입니다. 번역 중에는 채팅이 없어도 상자가 보이며, 클릭은 그대로 게임으로 통과합니다. **게임 프로필 → 번역창과 단축키 → 반투명 배경 상자**에서 켜고 상자 불투명도(0.1~0.9)를 정할 수 있습니다. 기본값은 꺼짐입니다.

## 1.0.2에서 바뀐 점

- **Codex 최신 버전 자동 사용:** Codex 모델 목록에 GPT-5 계열 옛 모델만 나오던 문제를 고쳤습니다. 이전에는 처음 찾은 Codex(예: VS Code 확장에 들어 있는 오래된 버전)를 계속 썼습니다. 이제 ChatGPT 앱·Codex 설치판·npm·VS Code 확장에 있는 Codex를 모두 찾아 가장 최신 버전을 사용하고, 사용 중인 버전과 설치 위치를 보여 줍니다. 이전에 자동으로 찾아 저장된 경로는 자동 선택으로 바뀝니다. 찾아보기로 직접 지정한 경로는 그대로 쓰며, 더 새 버전이 있으면 알려 줍니다.
- **내 채팅 번역 입력 창:** 배경 없이 글자만 보이는 **투명 배경**을 추가하고 기본값으로 했습니다. 밝은 화면에서도 읽히도록 글자를 굵게 하고 검은 외곽선을 둘렀으며, 글자 크기도 키웠습니다. 예전 모양은 **내 채팅 번역 → 입력 창 모양**에서 투명 배경을 끄면 됩니다.

## 1.0.1에서 바뀐 점

- **내 채팅 번역:** 번역 중 게임에서 **Shift+Enter**를 누르면 입력 창이 뜹니다. 한국어로 입력하고 Enter를 누르면 선택한 언어로 번역해 클립보드에 넣으니, 게임 채팅에 **Ctrl+V**로 붙여 넣으세요. ↑/↓로 언어를 바꾸고, 결과 확인 후 복사·한국어로 되돌려 확인을 선택할 수 있습니다. 게임에 자동으로 입력하지 않습니다.
- **번역 엔진 추가:** **Bing 무료 번역(비공식)**과 **Microsoft 번역(Azure, 월 200만 자 무료)**을 고를 수 있습니다. Bing은 게임 말투와 중국어가 구글 무료보다 자연스러운 편이며, 실패하면 구글 무료로 대신 번역합니다. Microsoft 번역은 무료 등급(F0)이 한도를 넘으면 요금 없이 멈추지만 Azure 설정 단계가 많습니다.
- **무료 번역 속도:** 구글·Bing 무료 번역이 여러 채팅을 최대 3개씩 동시에 번역합니다.
- **번역창 사라짐 수정:** 번역 중 번역창이 게임 창 뒤로 가려지면 다시 위로 올립니다. 키보드 포커스는 가져오지 않습니다.
- **새 버전 알림:** 앱을 켤 때 새 버전이 있으면 위쪽에 알리고, 변경 내용을 앱 안에서 볼 수 있습니다. 자동으로 내려받지 않으며 진단 · 테스트 탭에서 끌 수 있습니다.
- **화면 정리:** 새 **내 채팅 번역** 탭을 추가하고, **연결 설정**을 **번역 설정**으로, **용어집·상용구**를 한 탭으로 합쳤습니다.

## 업데이트 방법

실행 중인 앱을 종료하고 새 ZIP을 새 폴더에 풀어 실행하세요. 설정·용어집·API 키는 그대로 이어집니다.

## 사용 시 참고

- 내 채팅 번역 단축키는 번역 중에만 등록되며, 그동안 다른 앱의 같은 조합(예: 메신저 줄바꿈)도 입력 창을 엽니다. 설정에서 바꿀 수 있습니다.
- 작거나 흐린 글자·빠른 스크롤에서는 채팅이 잘못 인식되거나 누락될 수 있습니다. 번역 속도와 품질은 선택한 서비스와 네트워크 상태에 따라 달라집니다.
- 번역 중에는 다른 창으로 전환해도 지정한 화면 영역을 계속 읽습니다. 게임을 하지 않을 때는 번역을 중지하세요.
