# 1.1.2 공개 배포판

## 1.1.2에서 바뀐 점

- **욕설 가림(`****`)이 있는 채팅 인식 개선:** 욕설 필터로 가려진 부분에서 채팅이 잘려 앞부분만 번역되거나, 잘린 조각이 다른 사람의 채팅에 붙던 문제를 개선했습니다. 같은 채팅이 가림 기호를 읽거나 빠뜨리면서 여러 번 번역되던 문제도 개선했습니다.
- **같은 채팅의 중복 번역 감소:** 닉네임·채널이 흐려지거나 조금 다르게 읽힌 채팅, 서버 안내가 붙은 채팅, 광고가 반복되는 화면 속 채팅이 다시 번역되던 문제를 개선했습니다.
- **좌표·닉네임 인식 개선:** 지원 요청 등 채팅 끝의 지도 좌표(`X67.4, Y102.0`)가 잘리거나 다른 채팅에 붙던 문제, 닉네임과 내용 사이의 틈 때문에 채팅이 사라지던 문제, 클랜 태그 안에 콜론이 있는 닉네임이 잘못 나뉘던 문제를 개선했습니다.
- **채팅 읽기 중단 문제 개선:** 보이스챗 번역을 켠 채 앱에서 번역을 시작하면 채팅 읽기가 멈춰 있던 문제와, 다른 창을 보다 돌아오면 직전 채팅이 번역되지 않고 건너뛰어지던 문제를 개선했습니다.
- **광고 차단 강화:** 줄바꿈된 성인 사이트 광고가 번역창에 표시되던 문제를 개선했습니다.
- **WarDogs 용어 추가:** 중국어 `复活车`를 "리스폰 차량"으로 번역합니다.
- **세션 로그 기록 안정화:** 다른 프로그램이 로그 파일을 읽는 동안 기록이 중단되던 문제를 개선했습니다.

## 1.1.1에서 바뀐 점

- **게임 포커스 문제 개선:** 보이스챗 번역이 켜져 있을 때 간헐적으로 게임에서 포커스가 빠지던 문제를 개선했습니다.

## 1.1.0에서 바뀐 점

- **보이스챗 번역 기능 추가:** 게임 보이스챗을 Windows 11의 라이브 캡션으로 글자로 바꿔 번역하고, 번역창에 채팅 번역과 함께 🎙 표시를 붙여 보여 줍니다. **음성 번역** 탭에서 **보이스챗 번역 사용**을 켜고 **듣는 언어**를 선택한 뒤 번역을 시작하면, 앱이 라이브 캡션을 해당 언어로 실행하고 창을 숨깁니다. 번역을 중지하면 라이브 캡션을 닫고 원래 설정으로 되돌립니다. 프리셋별로 저장되며 기본값은 꺼짐입니다.
- **음성 인식은 이 PC 안에서 처리:** 음성 인식은 라이브 캡션이 이 PC 안에서 처리하며 소리는 외부로 전송되지 않습니다. 인식된 문장만 채팅과 같은 번역 엔진으로 전송합니다. 세션 로그에는 채팅 내용 기록을 켜도 음성 문장과 번역을 남기지 않습니다.
- **사용 조건:** Windows 11 22H2 이상에서 사용할 수 있습니다. 라이브 캡션이 없는 PC(Windows 10 등)에서는 음성 번역 설정이 비활성화되고 그 이유가 표시되며, 채팅 번역은 그대로 사용할 수 있습니다.
- **처음 사용하는 언어:** 라이브 캡션 창이 열려 개인 정보 동의와 음성 인식 팩 내려받기를 안내합니다. 안내에 따라 진행하면 창이 숨겨지고 듣기를 시작합니다. 음성 인식 팩은 언어마다 한 번만 받으면 됩니다.

## 기존 사용자 안내

- 기존 설정·용어집·API 키는 그대로 유지됩니다.
- 보이스챗 번역은 모든 프리셋에서 꺼진 상태로 시작합니다. 사용하려면 **음성 번역** 탭에서 켜고 저장·적용하세요.
- 라이브 캡션을 미리 켜 두었다면 앱이 그 창을 그대로 사용합니다. 이 경우 듣는 언어를 바꾸지 않으며, 번역을 중지해도 라이브 캡션을 닫지 않습니다.
- 라이브 캡션 설정의 **마이크 오디오 포함**이 켜져 있으면 내 목소리도 번역됩니다.

## 1.0.8에서 바뀐 점

- **크롬 내장 번역 엔진 추가:** 크롬(138 이상)에 들어 있는 번역 모델로 이 PC 안에서 번역합니다. **번역할 채팅과 번역 결과는 이 PC 안에서만 처리되며 외부 서버로 전송되지 않습니다**(번역 서비스·개발자 모두 받지 않음). 무료이며 사용 한도가 없습니다. **번역** 탭에서 **일반 번역 → 크롬 내장 번역**을 선택하고 번역을 시작하면 크롬 창이 열립니다. 처음 쓰는 언어는 그 창에서 **받기**를 눌러 언어팩을 한 번 받아야 합니다. 은어·게임 말투 번역은 구글 클라우드 번역보다 약합니다.
- **파파고 무료 번역(비공식) 엔진 추가:** 계정·키 없이 네이버 파파고 웹사이트로 번역합니다. 번역에 실패하거나 파파고가 지원하지 않는 언어는 구글 무료 번역으로 대신 번역합니다.
- **구글 무료 번역 개선:** 같은 언어의 채팅을 최대 16줄까지 묶어 한 번에 보내 요청 제한에 덜 걸리며, 실패하면 다른 구글 주소로 다시 번역합니다.
- **화면 글자 한 번 번역 기능 추가:** **Ctrl+Alt+R**을 누르고 화면의 글자(퀘스트·공지·메뉴 등)를 드래그하면 그 부분만 읽어 번역해 옆에 표시합니다. 번역 중이 아니어도 사용할 수 있습니다.
- **인식 보정 기능 추가:** **게임 → 인식 보정**에서 채팅 탭·아이콘처럼 채팅이 아닌 부분을 제외 영역으로 지정하고, 배경이 비치는 채팅창은 글자 색을 골라 그 색의 글자만 읽게 할 수 있습니다. 자주 잘못 읽히는 글자는 **OCR 교정 사전**에 등록해 바로잡습니다.
- **프리셋 내보내기·가져오기 기능 추가:** 프리셋 설정과 프리셋 전용 용어·상용구를 파일 하나(`.zmpreset.json`)로 저장하고 불러옵니다. API 키는 포함하지 않습니다.
- **내 채팅 번역 개선:** 게임 채팅 글자 수 제한(WarDogs 64자)보다 긴 번역은 나눠서 차례로 복사합니다. 또한 '자주포'처럼 용어집에 중국어 표기가 함께 있는 용어가 영어 채팅에 한자로 들어가던 문제를 수정했습니다. 이제 번역할 언어에 맞는 표기를 사용합니다.
- **번역창 숨기기 단축키·알림 영역 아이콘 추가:** **Ctrl+Alt+H**를 누르면 번역은 계속하면서 번역창만 숨깁니다. 작업 표시줄 알림 영역의 ZM 아이콘에서 번역 시작·중지와 종료를 할 수 있습니다.
- **인식·번역 오류 수정:** 한글 닉네임이 `7|`처럼 다른 글자로 읽히던 문제를 개선하고, 게임을 종료한 뒤 다른 프로그램 화면을 계속 읽던 문제를 수정했습니다. 위챗 대리 게임 광고도 번역하지 않습니다.

## 1.0.7에서 바뀐 점

- **프리셋 기능 추가:** 기존 게임 프로필을 프리셋으로 확장했습니다. 제어판 상단의 프리셋 목록에서 선택하면 번역 엔진·모델, 번역 동작, 번역창 위치·크기·글자, 내 채팅 번역 설정, 게임 정보·채팅 영역이 한 번에 적용됩니다. 프리셋 생성·복제·삭제를 지원하며, 프리셋별로 저장되는 설정에는 '프리셋별' 표시가 붙습니다. API 키·단축키·로그·구글 클라우드 월 상한은 모든 프리셋에 공통으로 적용되므로 프리셋을 변경해도 과금 관련 설정은 바뀌지 않습니다.
- **WarDogs 전용 처리를 프리셋으로 분리:** 팀 색상 표시, 상자 위 `OWNER` 표시 제외, 채팅 인식 규칙, FOB·핫존·T1/T2 등의 용어를 WarDogs 프리셋으로 분리했습니다. 다른 게임에서는 '기본' 프리셋이나 새 프리셋을 사용하시면 됩니다.
- **용어집 적용 범위 설정 추가:** 용어마다 모든 프리셋에 적용할지, 현재 프리셋에만 적용할지 선택할 수 있습니다. 용어집과 상용구 목록에는 현재 프리셋에 적용되는 항목만 표시됩니다.
- **UI 개선:** Windows 11 스타일 디자인을 적용하고, 설정을 실시간 번역 · 게임 · 번역 · 번역창 · 내 채팅 번역 · 용어집·상용구 · 앱 설정 · 로그·진단 탭으로 재구성했습니다. 설정 마법사 버튼은 제어판 오른쪽 아래로 이동했습니다.
- **내 채팅 번역 위치 변경 기능 추가:** 입력 창 위치를 화면 중앙(기본) · 채팅 영역 근처 · 커스텀 위치(직접 옮겨 둔 위치) 중에서 선택할 수 있습니다.
- **내 채팅 번역 단축키 동작 개선:** Shift+Enter는 번역 중 게임 창이 활성화되어 있을 때만 입력 창을 엽니다. 메신저·브라우저 등 다른 프로그램에서는 기존처럼 줄바꿈으로 동작합니다.
- **API 키 발급 안내 추가:** 번역 탭의 구글 클라우드 번역·Microsoft 번역에 **API 키 발급하기** 버튼을 추가했습니다. 발급 페이지 이동부터 연결 확인까지 단계별로 안내합니다.

## 1.0.6에서 바뀐 점

- **채팅 입력 시 지난 채팅 중복 번역 개선:** Enter를 눌러 채팅을 입력할 때 WarDogs가 다시 표시하는 지난 채팅(팀 채팅 등)을 새 채팅으로 인식해 다시 번역하던 문제를 수정했습니다. 닉네임이 일시적으로 잘못 인식되어도 같은 채팅으로 처리합니다.
- **다른 창이 채팅을 가리면 읽기 일시 중지 (기본 켜짐):** 번역 중 브라우저·메일 등 다른 프로그램이 채팅 영역을 가리면 읽지 않으며, 게임 화면으로 돌아오면 다시 읽습니다. 다른 창의 글자는 번역 서비스로 전송되지 않습니다. **게임** 탭(1.0.7 기준)에서 기능을 끄거나 게임 프로그램을 직접 선택할 수 있으며, 게임으로 판단되는 프로그램은 ★로 먼저 표시합니다.
- **번역창 화면 캡처·방송 숨기기 기능 추가 (선택):** 켜면 스크린샷·녹화·디스코드/OBS 화면 공유에 번역창과 내 채팅 번역 입력 창이 표시되지 않고 내 화면에만 표시됩니다. **앱 설정** 탭(1.0.7 기준)에서 설정합니다.
- **성능 개선:** 광고가 계속 올라오는 경우나 메뉴 화면에서 글자 인식이 불필요하게 늘어나던 문제를 수정했습니다.
- **번역 오류 수정:** `in`처럼 짧은 영어 한 단어가 번역 실패로 표시되던 문제를 수정했습니다.

## 1.0.5에서 바뀐 점

- **일반 번역(구글·Bing·Microsoft) 품질 개선:**
  - 게임 약어를 풀어서 번역합니다. 예: `omw` → "가는 중이야", `mb` → "내 잘못이야", `spawn vic` → "스폰 차량", `lmao`·`www` → "ㅋㅋ". 용어집의 새 처리 방식 **번역 전 바꾸기**에 포함되어 있어 수정·해제하거나 직접 추가할 수 있습니다.
  - 짧은 번체 중국어(예: `牆外有人`)가 번역되지 않고 그대로 표시되던 문제를 수정했습니다. 글자를 기준으로 중국어·영어·일본어를 판별해 전송합니다.
  - 욕설 필터로 가려진 `****`가 번역 과정에서 누락되거나 문장의 뜻이 바뀌지 않도록 그대로 유지합니다.
  - 고정 용어 뒤의 조사를 받침에 맞게 조정하고("핫존로" → "핫존으로"), 중국어 문장에서 붙어서 출력되던 단어를 띄어 씁니다.
- **WarDogs 기본 용어 추가:** 핫존(`HZ`·`hot zone`·`热区`), 컨트롤 존(`CZ`·`控制区`), 핵쟁이(`cheater`), 열화상(`thermals`), 자주포(`攀枝花`·`PZH`), 공격헬기(`武直`), 핵 쓰다(`开挂`)를 추가하고 `Havoc`은 원문 그대로 유지합니다. 소문자 `fob`도 FOB로 유지합니다. 기존 설정에는 한 번만 추가되며, 삭제한 용어는 다시 추가되지 않습니다.
- **용어집 검색·필터 추가:** 검색 칸과 처리 방식 필터를 추가했습니다. "대소문자 구분", "단어 단위만" 항목에 마우스를 올리면 예시와 함께 설명을 표시합니다.
- **성능 최적화:** 채팅이 숨겨져 있거나 글자가 변하지 않았을 때 화면을 다시 읽는 횟수를 줄였습니다. 채팅 글자가 흰색이 아닌 게임에서는 놓친 채팅을 자동으로 감지해 인식 방식을 전환합니다.
- **채팅이 아닌 글자 제외:** 채팅 영역에 겹친 다른 프로그램의 메모리 사용량·시각 표시를 채팅으로 번역하지 않습니다.
- **Claude 엔진 개선:** PC 환경 변수에 Anthropic API 키가 있어도 사용하지 않으며, 항상 로그인한 본인의 Claude 요금제로 번역합니다.

## 1.0.4에서 바뀐 점

- **광고·스팸 채팅 번역 제외 기능 추가:** 핵 판매 사이트, QQ 그룹 모집, 성인 사이트 광고처럼 사이트 주소·연락처와 판매 문구가 함께 있는 채팅은 번역하지 않으며 번역창에도 표시하지 않습니다. 번역 요청을 보내지 않으므로 유료 번역 사용량도 줄어듭니다. "he is cheating", "挂", "举报"처럼 핵 관련 일반 대화는 그대로 번역합니다. 광고로 판단한 채팅은 실시간 번역 탭의 기록 목록에 남아 있으며, 잘못 걸러진 경우 선택 후 **다시 번역**할 수 있습니다. **번역** 탭(1.0.7 기준)의 번역 동작에서 기능을 끄거나 번역창에 "광고로 판단해 번역하지 않음"으로 표시하도록 변경할 수 있습니다.
- **상자 소유자 표시 오인식 수정:** WarDogs에서 상자 위에 표시되는 `OWNER: 이름`·`상자 내구도`가 채팅 영역에 겹치면 채팅으로 인식되어 닉네임이 번역되던 문제(예: LION → 사자)를 수정했습니다.
- **Claude (계정 로그인) 엔진 추가:** 직접 설치하고 로그인한 Claude Code를 통해 API 키 없이 본인의 Claude 요금제(Pro·Max) 한도 내에서 AI 번역을 사용할 수 있습니다. **번역** 탭(1.0.7 기준)에서 **AI 번역 → Claude (계정 로그인)**을 선택하고 **연결 확인**을 누르세요. 앱은 Claude 계정 정보를 다루지 않으며, 장시간 번역하면 요금제 한도가 빠르게 소진될 수 있습니다.
- **성능 최적화:** 채팅 글자가 바뀌지 않았으면(뒤의 게임 화면만 움직이는 경우) 글자 인식을 건너뛰며, 메모리 사용량을 약 300MB 줄였습니다. CPU가 부족할 때는 게임이 먼저 처리되도록 우선순위를 낮췄습니다.
- **앱 아이콘 추가:** 프로그램 로고를 제작해 exe와 창·작업 표시줄 아이콘에 적용했습니다.

## 1.0.3에서 바뀐 점

- **번역창 반투명 배경 상자 추가:** 번역창 뒤에 어두운 반투명 상자를 표시하는 옵션을 추가했습니다. 번역이 표시되는 위치를 쉽게 알 수 있고, 밝은 화면에서도 글자가 잘 보입니다. 번역 중에는 채팅이 없어도 상자가 표시되며, 클릭은 그대로 게임으로 전달됩니다. **번역창** 탭(1.0.7 기준)의 **반투명 배경 상자**에서 켜고 상자 불투명도(0.1~0.9)를 설정할 수 있습니다. 기본값은 꺼짐입니다.

## 1.0.2에서 바뀐 점

- **Codex 최신 버전 자동 사용:** Codex 모델 목록에 GPT-5 계열의 이전 모델만 표시되던 문제를 수정했습니다. 이전에는 처음 찾은 Codex(예: VS Code 확장에 포함된 이전 버전)를 계속 사용했습니다. 이제 ChatGPT 앱·Codex 설치판·npm·VS Code 확장에 있는 Codex를 모두 찾아 가장 최신 버전을 사용하며, 사용 중인 버전과 설치 위치를 표시합니다. 이전에 자동으로 찾아 저장된 경로는 자동 선택으로 변경됩니다. 찾아보기로 직접 지정한 경로는 그대로 사용하며, 더 최신 버전이 있으면 알려 드립니다.
- **내 채팅 번역 입력 창 투명 배경 추가:** 배경 없이 글자만 표시하는 **투명 배경**을 추가하고 기본값으로 설정했습니다. 밝은 화면에서도 읽을 수 있도록 글자를 굵게 하고 검은 외곽선을 적용했으며, 글자 크기도 키웠습니다. 이전 모양을 사용하려면 **내 채팅 번역 → 입력 창 모양**에서 투명 배경을 끄면 됩니다.

## 1.0.1에서 바뀐 점

- **내 채팅 번역 기능 추가:** 번역 중 게임에서 **Shift+Enter**를 누르면 입력 창이 표시됩니다. 한국어로 입력하고 Enter를 누르면 선택한 언어로 번역해 클립보드에 복사하므로, 게임 채팅에 **Ctrl+V**로 붙여 넣으세요. ↑/↓로 언어를 변경할 수 있으며, 결과 확인 후 복사·한국어로 되돌려 확인 기능을 선택할 수 있습니다. 게임에 자동으로 입력하지는 않습니다.
- **번역 엔진 추가:** **Bing 무료 번역(비공식)**과 **Microsoft 번역(Azure, 월 200만 자 무료)**을 선택할 수 있습니다. Bing 번역이 실패하면 구글 무료 번역으로 대신 번역합니다. Microsoft 번역은 무료 등급(F0) 한도를 넘으면 요금 없이 중지되지만, Azure 설정 단계가 많습니다.
- **무료 번역 속도 개선:** 구글·Bing 무료 번역이 여러 채팅을 최대 3개씩 동시에 번역합니다.
- **번역창 사라짐 수정:** 번역 중 번역창이 게임 창 뒤로 가려지면 다시 위로 표시합니다. 키보드 포커스는 가져오지 않습니다.
- **새 버전 알림 추가:** 앱 실행 시 새 버전이 있으면 상단에 알리고, 변경 내용을 앱 안에서 확인할 수 있습니다. 자동으로 다운로드하지 않으며, **앱 설정** 탭(1.0.7 기준)에서 끌 수 있습니다.
- **화면 정리:** **내 채팅 번역** 탭을 추가하고, **연결 설정**을 **번역 설정**으로 변경했으며, **용어집·상용구**를 한 탭으로 통합했습니다.

## 업데이트 방법

실행 중인 앱을 종료한 뒤 새 ZIP 파일을 새 폴더에 압축 해제하여 실행하세요. 설정·용어집·API 키는 그대로 유지됩니다.

## 사용 시 참고

- 숨겨졌던 채팅이 다시 나타날 때 첫 메시지가 최대 2초 늦게 표시될 수 있습니다.
- 작거나 흐린 글자, 빠른 스크롤에서는 채팅이 잘못 인식되거나 누락될 수 있습니다. 번역 속도와 품질은 선택한 서비스와 네트워크 상태에 따라 달라집니다.
- 채팅 영역에 게임이 아닌 창이 표시되면 읽기를 일시 중지합니다. 게임을 하지 않을 때는 번역을 중지해 주세요.
- 파파고·구글·Bing 무료 번역은 공개 API가 아닌 비공식 방식이라 언제든 제한되거나 중단될 수 있습니다.
- 크롬 내장 번역은 크롬 138 이상이 설치된 PC에서만 사용할 수 있습니다. 인터넷은 언어팩을 처음 받을 때만 사용하며(크롬이 Google에서 내려받음), 채팅 내용은 함께 전송되지 않습니다.
- 보이스챗 번역은 누가 말했는지 구분하지 않으며, 라이브 캡션은 한 번에 한 언어만 인식합니다. 여러 사람이 동시에 말하거나 게임 소리가 크면 인식이 틀릴 수 있습니다. 러시아어는 라이브 캡션이 지원하지 않습니다.
- 화면 캡처 숨기기는 Windows의 캡처 제외 기능을 사용합니다. 이 기능을 지원하지 않는 일부 캡처 프로그램에서는 번역창이 표시될 수 있습니다.
