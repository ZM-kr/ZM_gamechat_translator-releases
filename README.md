# ZM GameChat Translator

게임 화면에 표시되는 다양한 언어의 채팅을 읽어 **한국어 번역을 화면 위에 표시**하는 Windows용 범용 게임 채팅 번역기입니다.

- **프리셋:** 게임마다 번역 엔진·번역창·채팅 영역·용어를 프리셋으로 나누어 저장하고, 목록에서 선택해 한 번에 적용합니다. WarDogs용 프리셋(채널 인식·팀 색상·전용 용어)이 기본으로 포함되어 있습니다.
- **번역 엔진:** 구글 클라우드 번역(추천), Microsoft 번역(Azure), 구글·파파고·Bing 무료 번역(비공식), 크롬 내장 번역(무료 · 채팅이 이 PC 밖으로 나가지 않음), AI 번역(API 키 또는 Claude·Codex 계정 로그인, Gemini·Groq 무료 키), 로컬 모델 중에서 선택할 수 있습니다.
- **내 채팅 번역:** 번역 중 게임에서 Shift+Enter로 한국어를 입력하면 선택한 언어로 번역해 클립보드에 복사합니다. 게임 채팅 글자 수 제한보다 긴 번역은 나눠서 차례로 복사합니다.
- **보이스챗 번역:** Windows 11(22H2 이상)의 라이브 캡션으로 게임 보이스챗을 글자로 바꿔 번역하고, 채팅 번역과 함께 번역창에 표시합니다(프리셋별, 기본 꺼짐). 음성 인식은 이 PC 안에서 처리합니다.
- **화면 글자 한 번 번역:** Ctrl+Alt+R을 누르고 화면의 글자(퀘스트·공지·메뉴 등)를 드래그하면 그 부분만 번역합니다.
- **글자 인식:** 내장 OCR로 영어·중국어를 인식하며, Windows OCR과 언어팩으로 다른 언어도 인식할 수 있습니다. 인식 보정(제외 영역·글자 색 필터·OCR 교정 사전)으로 게임에 맞게 조정할 수 있습니다.
- **용어집과 번역창:** 용어를 모든 프리셋 공통 또는 특정 프리셋 전용으로 적용할 수 있으며, 번역창 위치·크기·글자와 반투명 배경 상자를 설정할 수 있습니다.
- 핵 판매·QQ 그룹·성인 사이트 같은 광고 채팅은 번역하지 않고 숨깁니다(설정에서 끌 수 있음).
- 로그 기록은 기본적으로 꺼져 있습니다.

## 다운로드

**현재 배포 버전: 1.1.2** · [다운로드 및 변경 사항](https://github.com/ZM-kr/ZM_gamechat_translator-releases/releases/tag/v1.1.2)

[배포 파일 보기](https://github.com/ZM-kr/ZM_gamechat_translator-releases/releases)

릴리스의 **Assets**에서 `ZM-GameChatTranslator-…-win-x64.zip` 파일을 받으세요. `Source code` ZIP은 이 안내 문서의 사본이며 프로그램이 아닙니다. `SHA256SUMS.txt`는 다운로드한 ZIP 파일의 손상 여부를 확인하는 데 사용합니다.

Windows x64용이며 .NET 런타임과 OCR 모델이 포함되어 있습니다. 최소 지원 환경은 Windows 10 2004 이상이며, 보이스챗 번역은 Windows 11 22H2 이상에서 사용할 수 있습니다.

## 시작하기

1. ZIP 파일을 모두 압축 해제하고 `ZM.GameChatTranslator.exe`를 실행합니다.
2. 처음 열리는 **설정 마법사**에서 **일반 번역 → 구글 클라우드 번역**을 선택하고, 안내에 따라 Google Cloud 프로젝트·결제 계정·API 키를 설정한 뒤 연결을 확인합니다. 사용량에 따라 요금이 발생할 수 있습니다.
3. 게임에 맞는 프리셋을 선택합니다. WarDogs는 **WarDogs**, 그 밖의 게임은 **기본 · 다른 게임**을 선택합니다.
4. 게임을 창 모드 또는 테두리 없는 창 모드로 실행하고 **채팅 영역**을 지정합니다.
5. 번역창 위치를 정하고 **완료하고 번역 시작**을 누릅니다. 기본 단축키는 **Ctrl+Alt+T**입니다.

마법사를 닫은 뒤에도 제어판 오른쪽 아래 **설정 마법사** 버튼으로 다시 열 수 있습니다.

[처음 실행 안내](START-HERE.txt) · [사용 안내](docs/TESTER-GUIDE.md) · [변경 사항](docs/RELEASE-NOTES.md)

**내 채팅 번역:** 번역 중 게임에서 **Shift+Enter**를 누르면 입력 창이 표시됩니다. 한국어로 입력하고 Enter를 누르면 선택한 언어로 번역해 클립보드에 복사하므로, 게임 채팅에 **Ctrl+V**로 붙여 넣으세요. ↑/↓로 언어를 변경합니다. 단축키는 게임 창이 활성화되어 있을 때만 동작하며, 다른 프로그램에서는 기존 Shift+Enter 동작이 그대로 유지됩니다. 번역이 게임 채팅 글자 수 제한(WarDogs 64자)보다 길면 나눠서 보여 주며, Enter로 한 부분씩 복사합니다. 언어·글자 수 제한·입력 창 모양과 위치는 **내 채팅 번역** 탭에서 설정하며, 게임에 자동으로 입력하지는 않습니다.

내장 OCR이 지원하는 영어·중국어 외의 언어는 **앱 설정 → 고급 · Windows OCR 호환 모드**에서 해당 언어팩을 설치하고 사용할 언어를 선택한 뒤 **저장·적용**하세요. 인식 가능한 언어는 Windows OCR 지원 목록에 따릅니다.

## 업데이트

앱을 실행할 때 새 버전이 있으면 상단에 알리고 변경 내용을 표시합니다. 앱을 종료하고 새 ZIP 파일을 새 폴더에 압축 해제해 실행하면 설정·용어집·API 키는 그대로 유지됩니다. 자동으로 다운로드하거나 설치하지 않습니다. 버전별 안내는 [변경 사항](docs/RELEASE-NOTES.md)의 **기존 사용자 안내**를 참고하세요. 1.0.6 이하에서 업데이트하면 기존 게임 프로필이 프리셋으로 전환됩니다.

## 스마트 앱 컨트롤(SAC)로 실행이 차단될 때

배포판은 코드 서명이 없어 Windows가 실행을 차단할 수 있습니다. 받은 파일과 배포자를 신뢰하고 설정 변경에 동의한다면 **Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정 → 끄기**를 선택한 뒤 다시 실행할 수 있습니다.

이 앱만 허용하는 기능은 없으며 **PC 전체의 SAC 보호가 꺼집니다.** Defender 실시간 보호는 켜 두세요. 최신 Windows 업데이트에서는 SAC를 다시 켤 수 있지만, 이전 버전에서는 Windows 초기화·재설치가 필요할 수 있습니다. 변경 전 업데이트와 설정 화면의 안내를 확인하세요. 다시 켜면 앱이 다시 차단될 수 있습니다.

설정 변경은 선택 사항입니다. 변경을 원하지 않으면 차단 문구를 제보해 주세요. [Microsoft 공식 FAQ](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

## 안티치트 및 사용 책임 안내

이 앱은 게임 프로세스에 연결하거나 게임의 메모리를 읽고 쓰지 않습니다. 게임 DLL을 주입하거나 게임의 네트워크 통신을 가로채지 않으며, 게임 내부에 후킹하지 않습니다. 화면 캡처에는 데스크톱 픽셀을 읽는 GDI BitBlt를 사용하고, 단축키는 Windows의 RegisterHotKey로 등록합니다. 보이스챗 번역을 켜면 Windows 라이브 캡션을 실행하고, 그 창의 글자를 화면 읽기 프로그램과 같은 UI 자동화로 읽습니다. 게임 창은 읽지 않습니다. 현재 앱 소스에는 OpenProcess, ReadProcessMemory, WriteProcessMemory, SetWindowsHookEx 호출이 없습니다.

지정한 데스크톱 영역을 캡처한 뒤 내장 OCR 또는 Windows OCR로 글자를 인식하고, 번역에 필요한 텍스트를 선택한 번역 API 또는 로컬 서버로 전송합니다. 화면 캡처를 이용한다는 점에서는 스크린샷·화면 녹화 도구와 비슷하지만, **게임이나 안티치트가 이 앱을 동일하게 취급하거나 허용한다는 뜻은 아닙니다.**

**어떤 게임에서도 제재 없이 사용할 수 있다고 보장하지 않습니다.** 안티치트의 탐지 기준은 공개되지 않을 수 있고 수시로 변경됩니다. 게임과 함께 실행되는 외부 프로그램이라는 이유로 탐지되거나 제한될 가능성을 배제할 수 없습니다. 사용 전 해당 게임의 외부 도구 사용 정책을 확인하세요.

**사용 여부와 그에 따른 위험은 사용자 본인이 판단하고 부담합니다.** 관련 법령이 허용하는 범위에서 개발자와 기여자는 이 앱 사용으로 인한 계정 정지·경고·기타 계정 제재, 성능 저하, 데이터 손실 또는 그 밖의 결과에 대해 책임을 지지 않습니다. 이러한 위험에 동의하지 않는다면 사용하지 마세요.

## 사용 시 알아둘 점

- 번역 중 채팅 영역에 게임이 아닌 창이 표시되면 읽기를 일시 중지합니다(기본 켜짐, **게임** 탭에서 변경). 게임을 하지 않을 때는 번역을 중지하세요.
- 화면 이미지는 로컬에서 처리하고, 번역에 필요한 텍스트는 선택한 번역 서비스로 전송합니다. 크롬 내장 번역을 선택하면 채팅과 번역 결과도 이 PC 안에서만 처리되며 외부 서버로 전송되지 않습니다. 보이스챗 번역의 음성 인식은 라이브 캡션이 이 PC 안에서 처리하며 소리는 전송하지 않고, 인식된 문장만 번역 서비스로 전송합니다. 로그는 기본적으로 꺼져 있으며 자동으로 전송하지 않습니다.
- 작은 글자·빠른 스크롤·복잡한 배경에서 OCR 오인식이 발생할 수 있습니다. 번역 속도와 품질은 서비스에 따라 달라집니다.
- 구글·파파고·Bing 무료 번역은 비공식 연결 방식이라 제한이나 중단이 발생할 수 있습니다. 파파고·Bing 무료 번역이 실패하면 해당 채팅은 구글 무료 번역으로 번역합니다.
- 앱을 실행할 때 GitHub에서 새 버전 여부를 한 번 확인합니다. 앱 이름과 버전만 전달하며 **앱 설정** 탭에서 끌 수 있습니다.
- 게임별 외부 도구 사용 정책을 확인하세요. 모든 게임과의 호환성을 보장하지 않습니다.
