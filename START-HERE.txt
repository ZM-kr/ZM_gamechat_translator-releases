ZM GameChat Translator · 1.1.0 공개 배포판

게임 채팅을 화면에서 읽어 한국어 번역을 표시하는 Windows용 범용 게임 채팅 번역기입니다.
Windows 11에서는 게임 보이스챗도 라이브 캡션으로 글자로 바꿔 번역할 수 있습니다.
프리셋으로 게임마다 설정을 나누어 사용할 수 있으며, WarDogs용 프리셋이 기본으로 포함되어 있습니다.
OCR 오인식, 번역 지연·누락이 발생할 수 있습니다.

안티치트 및 사용 책임 안내

이 앱은 게임 프로세스에 연결하거나 게임의 메모리를 읽고 쓰지 않습니다. 게임 DLL을 주입하거나 게임의 네트워크 통신을 가로채지 않으며, 게임 내부에 후킹하지 않습니다. 화면 캡처에는 데스크톱 픽셀을 읽는 GDI BitBlt를 사용하고, 단축키는 Windows의 RegisterHotKey로 등록합니다. 채팅 영역에 게임이 표시되는지 확인할 때는 화면에 보이는 창과 그 프로세스 번호(GetForegroundWindow, WindowFromPoint, GetWindowThreadProcessId), 작업 관리자와 같은 프로세스 목록만 확인합니다. 보이스챗 번역을 켜면 Windows 라이브 캡션을 실행하고, 그 창의 글자를 화면 읽기 프로그램과 같은 UI 자동화로 읽습니다. 게임 창은 읽지 않습니다. 현재 앱 소스에는 OpenProcess, ReadProcessMemory, WriteProcessMemory, SetWindowsHookEx 호출이 없습니다.

지정한 데스크톱 영역을 캡처한 뒤 내장 OCR 또는 Windows OCR로 글자를 인식하고, 번역에 필요한 텍스트를 선택한 번역 API 또는 로컬 서버로 전송합니다. 화면 캡처를 이용한다는 점에서는 스크린샷·화면 녹화 도구와 비슷하지만, 게임이나 안티치트가 이 앱을 동일하게 취급하거나 허용한다는 뜻은 아닙니다.

어떤 게임에서도 제재 없이 사용할 수 있다고 보장하지 않습니다. 안티치트의 탐지 기준은 공개되지 않을 수 있고 수시로 변경됩니다. 게임과 함께 실행되는 외부 프로그램이라는 이유로 탐지되거나 제한될 가능성을 배제할 수 없습니다. 사용 전 해당 게임의 외부 도구 사용 정책을 확인하세요.

사용 여부와 그에 따른 위험은 사용자 본인이 판단하고 부담합니다. 관련 법령이 허용하는 범위에서 개발자와 기여자는 이 앱 사용으로 인한 계정 정지·경고·기타 계정 제재, 성능 저하, 데이터 손실 또는 그 밖의 결과에 대해 책임을 지지 않습니다. 이러한 위험에 동의하지 않는다면 사용하지 마세요.

처음 실행하기
1. ZIP 파일을 마우스 오른쪽 버튼 → 모두 압축 풀기로 압축 해제하세요.
   압축을 풀지 않고 ZIP 안에서 바로 실행하지 마세요.
2. 폴더 안의 ZM.GameChatTranslator.exe를 실행하세요.
   .NET 런타임과 내장 OCR 모델이 포함되어 있습니다.
   내장 OCR은 언어팩 없이 영어·중국어를 인식하고 한국어를 보완합니다.
   다른 언어는 [앱 설정 → 고급 · Windows OCR 호환 모드]에서 해당 언어팩을
   설치하고 사용할 언어를 선택한 뒤 저장·적용하세요.
   Windows 10 2004 이상 또는 Windows 11의 x64 PC에서 사용할 수 있습니다.
3. 처음 실행하면 설정 마법사가 열립니다. 순서대로 진행하세요.
   마법사를 닫은 뒤에도 제어판 오른쪽 아래 [설정 마법사] 버튼으로 다시 열 수 있습니다.
   ① 번역 엔진: [일반 번역 → 구글 클라우드 번역](추천)을 권장합니다.
      Google Cloud 프로젝트 만들기 → 결제 계정 연결 → API 사용 → API 키 발급
      순서로 안내에 따라 설정하고 [연결 확인]으로 확인하세요.
      무료 한도를 초과하면 요금이 청구될 수 있으며, 앱의 월 상한은 기본 45만 자입니다.
      처음에는 구글 무료 번역(비공식)이 선택되어 있으니 직접 변경하세요.
      - API 키 없이 시작하려면 구글·파파고·Bing 무료 번역(비공식)을 선택할 수 있습니다.
      - 크롬 내장 번역은 PC에 설치된 크롬(138 이상)으로 이 PC 안에서 무료로 번역합니다.
        채팅과 번역 결과는 이 PC 안에서만 처리되며 외부로 전송되지 않습니다.
        번역을 시작하면 크롬 창이 열리며, 언어마다 그 창에서 [받기]를 눌러
        언어팩을 한 번 받아야 합니다.
      - Microsoft 번역(Azure)은 매달 200만 자까지 무료이며, 한도를 넘으면
        요금 없이 중지됩니다. Azure 가입·리소스 생성 등 설정 단계가 많습니다.
      - AI 번역을 선택하면 [시작하기] 버튼이 표시됩니다. Google Gemini 3.8 Flash(추천)
        또는 Groq의 무료 키로 바로 체험할 수 있습니다. 무료 사용량이 적어 채팅이
        많은 게임에서는 도중에 한도에 도달할 수 있습니다.
      - 나중에 키를 발급하려면 번역 탭의 [API 키 발급하기] 버튼을 사용하세요.
   ② 게임: 게임에 맞는 프리셋을 선택하세요. WarDogs는 [WarDogs],
      그 밖의 게임은 [기본 · 다른 게임]을 선택합니다.
   ③ 채팅 영역: 게임을 창 모드 또는 테두리 없는 창 모드로 실행하고 채팅이 보이는
      상태에서 [채팅 영역 지정]으로 드래그하세요. 채널·닉네임·본문 전체와
      줄 왼쪽의 진영 표지(● ▼ ■)까지 포함하고 위아래에 여백을 두세요.
      [지금 화면 읽어 보기]로 인식 결과를 확인할 수 있습니다.
   ④ 번역창·단축키 → [완료하고 번역 시작]. Ctrl+Alt+T로 번역을 시작/중지합니다.

프리셋
- 제어판 상단의 프리셋 목록에서 선택하면 번역 엔진, 번역창, 내 채팅 번역 설정,
  게임 정보·채팅 영역이 한 번에 적용됩니다. '프리셋별' 표시가 있는 설정은
  프리셋마다 따로 저장됩니다.
- 새 게임은 [게임] 탭에서 새 프리셋을 만들어 사용하세요.
- API 키·단축키·로그·구글 클라우드 월 상한은 모든 프리셋에 공통으로 적용됩니다.
- [게임 → 프리셋]에서 프리셋을 파일로 내보내거나 가져올 수 있습니다(API 키 제외).
- 채팅이 아닌 글자가 함께 읽히거나 배경이 비치는 채팅창이라면
  [게임 → 인식 보정]에서 제외 영역·글자 색·OCR 교정 사전을 설정하세요.

단축키 (기본값, [앱 설정 → 단축키]에서 변경)
- Ctrl+Alt+T: 번역 시작/중지
- Ctrl+Alt+R: 화면 글자 한 번 번역 (드래그한 부분만 읽어 번역)
- Ctrl+Alt+H: 번역창 숨기기/표시 (번역은 계속)
- Shift+Enter: 내 채팅 번역 (번역 중 게임 창에서만)

보이스챗 번역 (Windows 11 22H2 이상)
- [음성 번역] 탭에서 [보이스챗 번역 사용]을 켜고 듣는 언어를 고른 뒤 저장·적용하세요.
  프리셋마다 따로 저장되며 기본은 꺼져 있습니다.
- 번역을 시작하면 Windows 라이브 캡션을 그 언어로 켜고 창을 숨깁니다. 들은 문장은
  번역창에 🎙 표시와 함께 나옵니다. 번역을 멈추면 라이브 캡션을 닫고 원래대로
  되돌립니다.
- 처음 쓰는 언어는 라이브 캡션 창이 열려 개인 정보 동의와 음성 인식 팩
  내려받기를 안내합니다. 안내에 따라 진행하면 창이 숨겨지고 듣기를 시작합니다.
- 라이브 캡션이 없는 PC(Windows 10 등)에서는 설정이 비활성화되고 이유가
  표시됩니다. 채팅 번역은 그대로 쓸 수 있습니다.
- 라이브 캡션의 [마이크 오디오 포함]을 켜면 내 목소리도 번역됩니다.

내 채팅 번역
- 번역 중 게임에서 Shift+Enter를 누르면 입력 창이 표시됩니다. 한국어로 입력하고
  Enter를 누르면 선택한 언어로 번역해 클립보드에 복사합니다. 게임 채팅에서
  Ctrl+V로 붙여 넣으세요. ↑/↓로 언어를 변경하고 Esc로 닫습니다.
- 번역이 게임 채팅 글자 수 제한(WarDogs 64자)보다 길면 나눠서 보여 줍니다.
  Enter로 첫 부분을 복사해 붙여 넣어 보낸 뒤, 단축키를 다시 누르면 다음 부분이
  나옵니다. 제한은 [내 채팅 번역] 탭에서 프리셋마다 정합니다.
- 단축키는 게임 창이 활성화되어 있을 때만 동작하며, 다른 프로그램에서는 기존
  Shift+Enter 동작(줄바꿈 등)이 그대로 유지됩니다.
- 언어·확인 후 복사·입력 창 모양과 위치(화면 중앙·채팅 영역 근처·커스텀 위치)는
  [내 채팅 번역] 탭에서, 단축키는 [앱 설정] 탭에서 변경합니다.
  게임에 자동으로 입력하지는 않습니다.

데이터와 비용
- 번역을 위해 인식한 채팅 글자를 선택한 번역 서비스로 전송합니다.
  화면 이미지는 전송하지 않습니다.
  · 구글 무료 번역(비공식): 채팅 본문이 Google로 전달됩니다. 요청 제한·실패가
    발생할 수 있습니다.
  · Bing 무료 번역(비공식)·Microsoft 번역: 채팅 본문이 Microsoft로 전달됩니다.
    Bing 무료 번역은 비공식 방식이라 언제든 차단될 수 있습니다.
  · 파파고 무료 번역(비공식): 채팅 본문이 네이버로 전달됩니다. 비공식 방식이라
    언제든 차단될 수 있으며, 실패한 채팅은 구글 무료 번역으로 대신 번역합니다.
  · 크롬 내장 번역: 채팅과 번역 결과는 이 PC 안에서만 처리되며 외부 서버로
    전송되지 않습니다. 인터넷은 언어팩을 처음 받을 때만 사용합니다(크롬이
    Google에서 내려받으며 채팅 내용은 함께 전송되지 않음).
  · 보이스챗 번역: 음성 인식은 라이브 캡션이 이 PC 안에서 하며 소리는 전송하지
    않습니다. 인식된 문장만 선택한 번역 서비스로 전송합니다.
  · Gemini 무료 등급: 전송한 채팅과 번역 결과가 Google 서비스 개선에 사용되며
    사람이 검토할 수 있습니다(Google 약관).
  · Codex·Claude·유료 API: 본인 계정 한도 또는 API 요금이 적용됩니다.
- 구글 클라우드 번역의 월 상한은 이 PC에서 전송한 글자만 집계합니다. 같은 키를
  다른 곳에서도 사용한다면 여유를 두고 설정하세요.
- 앱을 실행할 때 GitHub에서 새 버전을 한 번 확인합니다(앱 이름·버전만 전달).
  [앱 설정 → 새 버전 확인]에서 끌 수 있습니다.
- 세션 로그 자동 기록과 대화 내용 포함은 기본적으로 꺼져 있습니다.
  음성 문장과 그 번역은 내용 포함을 켜도 로그에 남기지 않습니다.
  오류 조사에 로그가 필요할 때만 [로그·진단] 탭에서 켜고 저장·적용하세요.
- 로그는 자동으로 전송되지 않습니다. 공유 전에 채팅 내용을 직접 확인하세요.
  API 키, settings.json, Codex 인증 파일은 공유하지 마세요.

사용 중 문제가 생기면
채팅이 잘못 인식되면 채팅 영역과 글자 크기를 확인하세요. 반복·누락·종료 등의
문제는 docs/BUG-REPORT.md 양식에 발생 시각과 함께 작성해 알려 주세요.
게임을 하지 않을 때는 번역을 중지해 다른 앱의 글자가 수집되지 않도록 하세요.

실행이 차단되면
- 이 실행 파일에는 디지털 서명이 없습니다.
- "Windows의 PC 보호" 경고가 표시되면, 먼저 SHA256SUMS.txt의 값과
  받은 ZIP 파일이 일치하는지 확인한 뒤 [추가 정보] → [실행]을 선택할 수 있습니다.
- "스마트 앱 컨트롤"이 차단했다면 아래 안내를 확인하세요.
  이 앱만 예외로 허용하는 기능은 없습니다. 받은 파일과 배포자를 신뢰하고
  설정 변경에 동의하는 경우에만 다음과 같이 직접 끌 수 있습니다.
  1. 시작 메뉴에서 [Windows 보안]을 엽니다.
  2. [앱 및 브라우저 컨트롤] → [스마트 앱 컨트롤 설정]을 엽니다.
  3. [끄기]를 선택하고 확인 창이 표시되면 내용을 확인합니다.
  4. 상태가 [끄기]인지 확인한 뒤 프로그램을 다시 실행합니다.
  이 변경은 이 앱뿐 아니라 PC 전체의 스마트 앱 컨트롤 보호를 끕니다.
  Defender 백신의 실시간 보호는 별도 설정이며 켜 둡니다.
  최신 Windows 업데이트에서는 다시 켜기를 지원하지만, 이전 버전에서는
  Windows 초기화·재설치가 필요할 수 있습니다. 변경 전 Windows 업데이트와
  해당 설정 화면의 재활성화 안내를 확인하세요. 다시 켜면 앱이 다시 차단될 수 있습니다.
  변경을 원하지 않거나, 설정이 없거나, 계속 차단된다면 경고 문구와 Windows 버전을 알려 주세요.
  Microsoft 공식 안내:
  https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions
- 글자는 인식되는데 채팅이 0개라면 채팅 영역과 닉네임 구분자(:)를 확인하세요.
