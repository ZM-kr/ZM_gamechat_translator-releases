ZM GameChat Translator · 0.4.30 공개 배포판

게임 채팅을 읽어 한국어 번역을 화면에 표시하는 Windows 프로그램입니다.
OCR 오인식, 번역 지연·누락이 발생할 수 있습니다.

안티치트 및 사용 책임 안내

이 앱은 게임 프로세스에 연결하거나 게임의 메모리를 읽고 쓰지 않습니다. 게임 DLL을 주입하거나 게임의 네트워크 통신을 가로채지 않으며, 게임 내부에 후킹하지 않습니다. 화면 캡처에는 데스크톱 픽셀을 읽는 GDI BitBlt를 사용하고, 단축키는 Windows의 RegisterHotKey로 등록합니다. 현재 앱 소스에는 OpenProcess, ReadProcessMemory, WriteProcessMemory, SetWindowsHookEx 호출이 없습니다.

지정한 데스크톱 영역을 캡처한 뒤 내장 OCR 또는 Windows OCR로 글자를 인식하고, 번역에 필요한 텍스트를 선택한 번역 API 또는 로컬 서버로 보냅니다. 화면 캡처를 이용한다는 점에서는 스크린샷·화면 녹화 도구와 비슷하지만, 게임이나 안티치트가 이 앱을 동일하게 취급하거나 허용한다는 뜻은 아닙니다.

어떤 게임에서도 제재 없이 사용할 수 있다고 보장하지 않습니다. 안티치트의 탐지 기준은 공개되지 않을 수 있고 수시로 변경됩니다. 게임과 함께 실행되는 외부 프로그램이라는 이유로 탐지되거나 제한될 가능성을 배제할 수 없습니다. 사용 전 해당 게임의 외부 도구 사용 정책을 확인하세요.

사용 여부와 그에 따른 위험은 사용자 본인이 판단하고 부담합니다. 관련 법령이 허용하는 범위에서 개발자와 기여자는 이 앱 사용으로 인한 계정 정지·경고·기타 계정 제재, 성능 저하, 데이터 손실 또는 그 밖의 결과에 대해 책임을 지지 않습니다. 이러한 위험에 동의하지 않는다면 사용하지 마세요.

처음 실행하기
1. ZIP을 마우스 오른쪽 버튼 → 모두 압축 풀기로 풀어 주세요.
   압축을 풀지 않고 ZIP 안에서 바로 실행하지 마세요.
2. 폴더 안의 ZM.GameChatTranslator.exe를 실행하세요.
   .NET 런타임과 내장 OCR 모델이 포함됩니다.
   내장 OCR은 언어팩 없이 영어·중국어를 읽고 한국어를 보완합니다.
   다른 언어는 [OCR 설정 → 고급 · Windows OCR 호환 모드]에서 해당
   지원 언어팩을 설치하고 사용할 언어를 선택한 뒤 저장·적용하세요.
   Windows 10 2004 이상 또는 Windows 11의 x64 PC가 대상이며,
   현재 검증 환경은 Windows 11입니다.
3. 처음 실행하면 설정 마법사가 열립니다. 순서대로 진행하세요.
   ① 번역 엔진: [일반 번역 → 구글 클라우드 번역]을 권장합니다.
      Google Cloud 프로젝트 → 결제 계정 연결 → API 사용 → API 키 발급
      순서로 안내를 따라 설정하고 [연결 테스트]로 확인하세요.
      무료 한도를 초과하면 과금될 수 있으며 앱의 월 상한은 기본 45만 자입니다.
      현재 0.4.30에서 구글 무료 번역이 선택되어 있으면 직접 변경하세요.
      - API 키 없이 시작하려면 구글 무료 번역도 선택할 수 있습니다.
      - AI 번역을 고르면 [무료로 시작하기] 버튼이 나옵니다. 눌러서
        Google Gemini 3.8 Flash(추천)나 Groq의 무료 키로 시작할 수
        있습니다. 무료 사용량이 적어 채팅이 많은 게임에서는 도중에
        한도에 걸릴 수 있습니다.
   ② 게임: WarDogs라면 [WarDogs 프리셋 적용]을 누르세요.
   ③ 채팅 영역: 게임을 창 모드나 테두리 없는 창 모드로 열고 채팅이 보이게 한
      뒤 [채팅 영역 지정]으로 드래그하세요. 채널·닉네임·본문 전체와
      줄 왼쪽의 진영 표지(● ▼ ■)까지 포함하고 위아래에 여백을 두세요.
      [지금 화면 읽어 보기]로 인식 결과를 확인할 수 있습니다.
   ④ 번역창·단축키 → [완료하고 번역 시작]. Ctrl+Alt+T로 시작/중지합니다.
   마법사는 제어판 위쪽 [설정 마법사] 버튼으로 다시 열 수 있습니다.

데이터와 비용
- 번역을 위해 인식한 채팅 글자를 선택한 번역 서비스로 보냅니다.
  화면 이미지는 보내지 않습니다.
  · 구글 무료 번역: 채팅 본문이 Google로 전달됩니다. 요청 제한·실패가
    생길 수 있습니다.
  · Gemini 무료 등급: 보낸 채팅과 번역 결과가 Google 서비스 개선에 쓰이고
    사람이 검토할 수 있습니다(Google 약관).
  · Codex·유료 API: 본인 계정 한도나 API 요금이 적용됩니다.
- 구글 클라우드 번역의 월 상한은 이 PC에서 보낸 글자만 셉니다. 같은 키를
  다른 곳에서도 쓰면 포함되지 않으니 여유를 두세요.
- 세션 로그 자동 기록과 대화 내용 포함은 기본으로 꺼져 있습니다.
  오류 조사에 로그가 필요할 때만 실사용 로그에서 켜고 저장·적용하세요.
- 로그는 자동 전송되지 않습니다. 공유 전 채팅 내용을 직접 확인하세요.
  API 키, settings.json, Codex 인증 파일은 보내지 마세요.

처음 사용 시 확인할 사항
- 외국어가 자연스럽게 번역되는지, 한국어 채팅이 영어처럼 잘못 읽히는지
- 같은 채팅이 여러 번 번역되는지, 새 채팅이 누락되거나 너무 늦는지
- WarDogs라면 번역창 닉네임이 진영 색(그린·레드·블루)으로 보이는지
- 번역 중 다른 창으로 전환하면 그 창의 글자가 번역되는지
  (지정한 화면 영역을 계속 읽습니다. 게임을 하지 않을 때는 번역을 중지하세요)
문제와 발생 시각은 docs/BUG-REPORT.md 양식으로 알려 주세요.

실행이 막히면
- 이 테스트 실행 파일에는 디지털 서명이 없습니다.
- "Windows의 PC 보호" 경고가 나오면, 먼저 SHA256SUMS.txt의 값과
  받은 ZIP이 같은지 확인한 뒤 [추가 정보] → [실행]을 선택할 수 있습니다.
- "스마트 앱 컨트롤"이 차단했다면 아래 안내를 확인하세요.
  이 앱만 예외로 허용하는 기능은 없습니다. 받은 파일과 배포자를 신뢰하고
  설정 변경에 동의하는 경우에만 다음과 같이 직접 끌 수 있습니다.
  1. 시작 메뉴에서 [Windows 보안]을 엽니다.
  2. [앱 및 브라우저 컨트롤] → [스마트 앱 컨트롤 설정]을 엽니다.
  3. [끄기]를 선택하고 확인 창이 나오면 내용을 확인합니다.
  4. 상태가 [끄기]인지 확인한 뒤 프로그램을 다시 실행합니다.
  이 변경은 이 앱뿐 아니라 PC 전체의 스마트 앱 컨트롤 보호를 끕니다.
  Defender 백신의 실시간 보호는 별도 설정이며 켜 둡니다.
  최신 Windows 업데이트에서는 다시 켜기가 지원되지만, 이전 버전에서는
  Windows 초기화·재설치가 필요할 수 있습니다. 변경 전 Windows 업데이트와
  해당 설정 화면의 재활성화 안내를 확인하세요. 다시 켜면 앱이 재차 차단될 수 있습니다.
  변경을 원하지 않거나 설정이 없거나 계속 차단되면 경고 문구와 Windows 버전을 알려 주세요.
  Microsoft 공식 안내:
  https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions
